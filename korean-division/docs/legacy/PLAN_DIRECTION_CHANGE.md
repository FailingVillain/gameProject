# 단기 계획 — 上1 방향 변경 대작업 (자리 비움 2시간용)

> 사용자가 "1번 진행" (또는 "방향 변경 시작") 하면 이 문서대로 실행한다. 확인 질문 없이 끝까지 진행하고, 돌아왔을 때 보고한다.
> 사양: `docs/ROADMAP.md` §0-1 (자원 · 생산 · 건물 · 공병 폐지, 유닛별 탄약 회복, 엄폐, 개인 참호 1단계).

## 0. 시작 조건 (Claude 가 먼저 확인)
- 게임 저장소의 다른 작업 브랜치 (편제 · 깃발 대형, 새 그림 반영, 스태미나) 가 **main 에 합쳐진 뒤** 시작한다. 안 끝났으면: 끝난 것만 합치고, 남은 브랜치는 그대로 둔 채 시작 (나중에 그 브랜치가 main 을 다시 병합).
- main 이 빌드 · `--detcheck` 통과 상태인지 확인 (下, Claude 직접).

## 1. 조사 — Gemini (비용 ≈ $0.1)
`python C:/works/agentHub/hub.py ask auto "<아래 질문>" -f <파일들> -r finder` 를 batch 로:
- 자원 (funds/steel/fuel/supplies/manpower) · 생산 (Produce/Queue/Train) · 건물 (Building defs · 건설 · 수리 · 부지) · 공병 (worker/engineer · Build/Repair/AssignBuilder) · 세력 보급 재고 (Supply storage · 보급소 · 연료 탱크 · Refuel) 와 연결된 **파일 · 클래스 · 함수 · 저장 필드 · 명령 · UI · AI · 테스트** 목록 (줄 번호 포함), 각 항목을 "삭제 / 수정 / 유지 (도시 · 점령지)" 로 분류.
- 결과를 `docs/legacy/REMOVAL_INVENTORY.md` 로 저장 (Claude 가 인용 줄 몇 개만 검증).

## 2. 구현 — opus 에이전트 1개 (上), 단계별 커밋
지시문 핵심 (에이전트에 그대로 전달):
1. `docs/legacy/REMOVAL_INVENTORY.md` 를 지도로 삼아 **제거**: 자원 5종 · 생산 · 건물 생성/건설/수리 · 공병 유닛 · 보급소/연료탱크/세력 재고 · 경제형 표준 AI 의 경제 부분 · 관련 UI (자원 막대 · 생산 카드 · 건설 메뉴) · 관련 테스트. **유지**: 도시 · 점령지 (점령 = 소유 변경, 목표 · 보급 가속), 교전 · 제압 · 계급 · 장교 · 돌격 · 기관총 · 편제 등 전투 시스템, 저장/리플레이/결정성 틀.
2. **새 보급**: 유닛별 탄약 한도 (무기 `ammo`), 교전 소모 그대로, 10초간 사격 · 피격 없으면 한도의 1%/초 회복, 아군 점거 도시 8칸 이내 ×3, 차량 · 포 동일 (연료 없음). 수치 balance.json.
2b. **보급 마차 유닛** (2026-10-19 추가): 비무장 수송 유닛, 주변 N칸 아군의 탄약 회복을 점령 도시 근처처럼 가속 (×3, 반경 6), 자체 적재량 소모 · 도시에서 재충전. 그림은 우선 차량 별칭.
3. **엄폐 시스템**: 유닛 `CoverLevel` (또는 배율) → 맞을 확률 × · 받는 제압 ×. 엄폐원 1 = 개인 참호 (명중 ×0.5 · 제압 ×0.5). `World.TerrainAccuracy` 자리 활용, 숲 · 언덕 등 추가 가능한 구조.
4. **개인 참호 (1단계)**: 보병 명령 '참호 파기' (+ 정지 N초 뒤 자동 옵션은 balance 플래그) → 파는 시간 (초기 8초) 뒤 참호 상태 · 이동하면 해제. 그림 = 유닛 아래 간단한 참호 표시 (렌더 쪽 최소 구현).
5. AI: 표준 AI 의 경제 · 생산 로직 제거 후 **주어진 병력으로 교전만** 하도록 축소 (캠페인 AI 는 나중).
6. 저장 형식 변경 → `Snapshot.FormatVersion` 올림, Audit 갱신, 골든 갱신.
7. 맵 · 시작 화면: 기존 맵의 건물 · 시작 유닛 정의를 "주어진 병력" 방식으로 (맵 json 에 유닛 배치 · 없으면 기본 편성 스폰).
검증: build → `--selftest` (실패는 제거된 기능 테스트 삭제 · 기대값 정리) → `--snaptest` → `--detcheck --update`/`--detcheck` → `--uifuzz 60` → `--stress CE` 전후 → `--balance sim infantry:200 vs 200` (엄폐 없음 / 참호 있음 비교 — **교전 템포 재측정**, ROADMAP §2-7).
