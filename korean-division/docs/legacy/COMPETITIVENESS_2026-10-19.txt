0. 읽기 전에 (방법과 한계)
--------------------------------------------------------------------------------
- 개정 2026-10-19 (2차): 사용자 지시에 따라 (A) 전투 기능만 깊게 재판정 (3절 전면
  교체), (B) 판매 수치를 raijin 단독이 아니라 교차검증 (4절 교체), 판매 전망을 비관
  기준 (수천 장) 으로 재작성했다. 캠페인 / 스토리 / 미션 / 음성 공백은 사용자가 알고
  있어 이번 개정에서 분석하지 않는다 (5절 일정표에만 남김).
- "상위 10 / 중위 10 / 하위 10" 은 총 30개 (요청문의 "20개" 와 달라 30개로 분석).
  티어 기준은 Steam 전체 순위가 아니라 "우리 게임과 비교할 만한" 후보군 안의 추정
  판매량과 평가.
- 2절 표의 판매 / 매출 수치는 raijin.gg 추정 (조회 2026-10-19, 정확도 "medium
  confidence", 보통 +-30% 이상 틀릴 수 있다). 4.3 에서 SteamSpy (API 직접 조회
  2026-10-19), Boxleiter (Steam 리뷰 수 x20~60, 2026-10-19 조회), VG Insights
  (steampulse, 일부는 검색 스니펫, 날짜 불명), 개발사 / 퍼블리셔 발표로 교차검증했다.
  Gamalytic 은 웹페이지가 JS 렌더링이고 API 는 키가 필요해 수치를 얻지 못했다.
- 팀 규모, 비교 게임의 전투 규모 / 캠페인 길이 / 리뷰 칭찬 · 불만, 3절의 장르 기준
  서술은 전부 내 사전 지식 (2026-06 기준) 이며 이번에 검증하지 않았다 ([기억 기반]).
- 우리 게임 수치는 repo 문서와 balance.json 에서 직접 인용했다. 이번에는 실제 exe
  (bin/main, 빌드 없음) 를 9회 실행해 화면 7장을 확인했다
  (docs/art_review/combat_review/). 단 포격 / 기병 돌격 순간은 포착하지 못했고
  소리는 무음으로 돌려 듣지 못했다 (3.0 참고).

1. 결론 요약 (전투 스타일 우선, 비관 판매)
================================================================================

[한 줄 판정]
전투는 "구현 폭은 상위 인디, 심리 축 (제압 -> 사기 -> 패주) 이 비어 있다" 이고,
판매는 비관 기준 수천 장 (1년 2~5천) 이다. 지금 상태로 경쟁력은 없다.

(1) 전투 판정 (3절, 상 / 중상 / 중 / 중하 / 하):
    규모 중상 | 가독성 중하 (진영색 안 보임) | 제압 하 | 사기 / 패주 하 | 엄폐 / 참호 중하
    | 대형 중 | 화력-기동 AI 중하 | 돌격 중하 | 포병 중하 | 기병 중하 | 지휘 중상
    | 조작 중 | 피드백 중하 | 전투 길이 중하 | 날씨 / 밤 중상 | AI 도전성 중하.
(2) 핵심 진단: 제압이 쌓이지 않고 (소총 28.6/s 대 감쇠 80/s, 교전 중 제압 중앙값 0)
    사기 상태가 없어 (한 판 사망 87%) 약진 / 돌격 / 후퇴 / 포병 / 기병이 모두 약하게
    보인다. 뿌리가 같다.
(3) 개선 우선 (3.18): 1 진영색 강화(下) 2 제압 재설계(中) 3 부사관 기본 편성(下)
    4 부대 기호 상태 표시(下) 5 사격 / 착탄 이펙트(下~中) ... 6 중대 사기(上).
(4) 시장 (2절): RTS 는 승자독식. 소규모 팀 역사 RTS 의 상한은 Regiments (약 7~8.5만
    장) 수준, 하위 사례는 수백~1만 장.
(5) 판매 전망 (4.3, 비관 기준): 기준 1년 누적 2~5천 장 (매출 약 4~10만 달러, 실수령
    약 2.5~6만 달러). 3천 / 5천 / 1만 장이 되려면 출시 시 위시리스트가 대략 4.3천 /
    7.1천 / 14.3천 개 필요 (Zukowski 2023-25 출시작 1년 판매 / 위시리스트 0.70 가정,
    [검색] 2025). 교차검증 결과 raijin 은 Boxleiter x20 부근의 보수적 값이고, 4개 게임
    (CoH3, Steel Division 2, UG: Gettysburg, Battle of Empires) 은 출처 간 2배 이상
    차이가 난다.
(6) 권고: 전투 개선 (1~5 번) 을 먼저 하고, 개선 뒤 같은 화면 (미션 연대전 줌 0.5~1.0)
    을 다시 찍어 진영 구분과 협동이 한눈에 읽히는지 확인할 것. Early Access 는
    위시리스트 7천 (약 5천 장 급) ~ 1.4만 개 확보 전에는 하지 말 것 (4.3).

우리 (balance.json 2026-10-19, ENGINE_NOTES 교전 개편 2차)

   0.26~0.29, 제압>0.3 병사 최대 29%).
 - 효과 자체도 약하다: 제압 1000 일 때 사격 간격 x2, 이동 -50%. 명중률 영향 없음,
   제자리 고정 (pin) 없음, 엄폐 찾기 없음 (balance.json "명중률 영향 없음").
   경기관총 +150 / 0.42초 (약 357/s) 로 유일하게 쌓지만 분산 사격 (spray) 이라 표적
   한 명당은 적다. 곡사포는 +400, 기병 돌격 충격 +300 (2칸 내).
 - 진행 중 변경 (superioritySupp 0.20) 은 "신호를 낮춰서 맞추는" 조치이며 제압 자체가
   쌓이게 하지는 않는다.
장르 기준 [기억 기반]
 - CoH: 기관총 / 분대 사격으로 분대가 엎드려 움직이지 못하는 pin -> 강제 후퇴. 제압이
   게임 루프의 중심 (한 번 pin 되면 기동조가 들어가는 신호). Close Combat: 병사
   개별 사기가 사격에 의해 pinned / broken / panic 으로 단계 상승, 가장 정교한 모델.
   SD2 / WARNO: 제압 -> 정확도 하락과 사기 하락 -> 패주. Regiments: 제압 -> 명중과
   이동 하락 + 은폐. Men of War: 제압 모델 약함 (병사 개별 시뮬 + 탄 관통). Total War:

판정: 하 (구현은 있으나 게임 루프에 거의 영향이 없고, AI 판단 신호도 거짓이다).

최고 가치 개선: 중대 사기 (사상 비율 + 제압 + 지휘 상실 + 측면 / 후방 피격) 와 패주.

3.18 전투 스타일 개선 우선순위 Top 10 (효과 / 노력 순, 진행 중 항목 제외)

 1. 진영색 강화 (하): 중간 줌 (0.5~1.0) 에서 팀색 링 / 어깨 / 헬멧 틴트. 효과 큼 (영상

 2. 제압 재설계 (중): 근접탄 제압 + 명중률 감소 + pin + 사수 합산. 3.3. 모든 AI 신호

    사용자 승인 후).
 3. 부사관 기본 편성 + 장교 전멸 대행 (하 + 중): 데이터만으로 None 78~94% 가 22~25% 로

 4. 부대 기호 상태 표시 (하): 엄호 / 약진 / 돌격 / 후퇴 / 유휴를 한 글자로. AI 의
    이상 행동이 의도로 읽힌다. 노력 下.
 5. 사격 / 피격 / 착탄 이펙트 (하~중): 소총 연기, 총구 섬광, 포 착탄 먼지 기둥,

    형식 + 골든 + 밸런스 전부 건드림. 노력 上. (2 번 이후에 착수.)

    일방 사격에서 벗어난다. 사람이 첫 번째로 하는 시험이 이 둘. 노력 中.

 9. 접촉선 두께 (하~중): 접촉 중 대형을 얇은 줄에서 두꺼운 덩어리로 (3.1). 효과: 화면의

10. 중대 정면 드래그 명령 (중): 선을 그어 폭 / 방향 지정 (TW 식). 수천 기 지휘의

     부를 수 있다. 완화 -> 허구 설정 명시, 실존 인물 사용 신중, 근대 군복/무기
     고증 오류 최소화 (한국 역사 커뮤니티의 고증 지적은 평점에 영향),
     중국/일본 관련 표현은 사전 검토. (가능성 판단: 증거 없음, 내 추정)

     art 방향을 맞춘다.
