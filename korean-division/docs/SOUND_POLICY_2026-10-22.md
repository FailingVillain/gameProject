# 소리 방침 초안 (2026-10-22)
1. **원칙**: 소리 변경은 표현 전용 (SfxDirector · sounds.json) — 시뮬 · 골든 불변. 새 음원 제작 없이 기존 kd1920 WAV 재사용 매핑부터, 맞는 음원이 없으면 가장 가까운 것을 쓰고 아래 목록에 기록.
2. **이번 연결 (sfxnew)**: 엽총 `shotgun` = 대전차소총 근접/원거리 WAV 재사용 (연결됨) · 타찬카 / 기마 포병 이동 = `wagon_loop` (연결됨) · 기병 하마/승마 전환 시작 = `mount_switch` (말 콧김 · 발구름, 연결됨).
3. **키만 준비 (breach 병합 후 연결)**: `mortar_fire(_far)` = 37mm포 발사음 재사용 · `mortar_impact(_far)` = 수류탄 폭발음 · `smoke_burst` = 수류탄 먼 폭발음 낮은 음량 · `wire_cut` = 근접 충돌음 낮은 음량. breach 미병합이라 박격포 무기 키 · 연막 / 철조망 사건이 main 에 없음.
4. **대체 음원 후보 (진짜 소리 아님)**: 연막은 쉬익 소리, 철조망은 금속 가위 소리, 박격포는 "퐁" 발사음이 맞음 — 지금 매핑은 임시. 사용자 승인 후 해당 WAV 만 추가 제작.
5. **무전 음성 임시본 교체 계획**: 현재 `audio-voice/` 변조 음성은 임시. 사용자 녹음 4대사 × en/de/ru (총 12개) 를 받으면 `voice_fx.py` 로 무전 변조 → `assets/voice/` 교체, 키 · 길이는 그대로 두어 코드 변경 없음. Gemini TTS 는 사용자 거절 (10-20) 이라 제외.
6. **세력별 함성 방침 후보**:
   - **A안: 공용 함성 1세트** (`charge_shout`) — 제작 최소, 일관됨. 단점: 세력 구분이 소리로는 안 됨.
   - **B안: 세력군 3묶음** (동아시아 · 슬라브 · 게르만/서구; 한국·일본·중국 / 러시아·소련 / 독일·영국) — 사용자 녹음 부담 적당, 구분 가능. 단점: 한중일 구분 못 함.
   - **C안: 세력별 개별 녹음** (한국·일본·러시아·소련·독일·마적 등) — 몰입 최고. 단점: 녹음 · 검수량 크고 사용자 목소리 한계로 대사가 비슷해짐.
   - 권장 B안 (필요하면 한국만 C안으로 승격).
7. **음량 · 혼잡**: 신규 키는 기존처럼 maxVoices · minInterval 로 폭주 방지 (수천 기 교전 대비), far 변형은 `farDist` 로 자동.
8. **검수**: 신규 키 청취는 `KD_SFX_BATTLE=1` 교전 테스트 (엽총수 · 타찬카 · 기병) 에서 사용자 확인.
