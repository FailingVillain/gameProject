## 1. 카메라

| 입력 | 동작 |
|---|---|
| 방향키 (← ↑ → ↓) | 화면 이동 |
| 화면 가장자리 | 창이 포커스를 갖고 커서가 창 안에 있을 때, 가장자리 8px 안이면 그 방향으로 스크롤 (`Config.EdgeScrollMargin`) |
| 가운데 버튼 드래그 | 화면 끌기 |
| 마우스 휠 | 커서 위치를 중심으로 확대 · 축소 |
| `+` / `-` (숫자패드 포함) | 화면 중앙 기준 확대 · 축소 |
| 미니맵 클릭 · 드래그 | 그 위치로 카메라 이동 (명령 대기 중이면 미니맵 지점에 명령) |
| `Space` | 선택한 부대의 중심으로 카메라 이동 |
| 연대 · 대대 번호 두 번 연타 (0.35초 안) | 그 연대 · 대대로 카메라 이동 (§2 참고) |
| `[` / `]` | 게임 속도 한 단계 낮춤 / 높임 (플레이: 0.5 · 1 · 1.5 · 2 · 3배) |
| `F3` | 일시정지 · 재개 (상단 버튼 "일시정지"도 같음). 일시정지 중에도 명령은 접수되고(대기열), 재개 첫 틱에 정확히 1회 실행됨 |
| 메인 메뉴 › 환경 설정 › 색각 대응 | 켜면 세력 색에 도형 표식(원 · 사각 · 삼각 · 마름모 · 십자, 세력 번호 순환)을 병기: 유닛 머리 위 · 축소 점 · 중대 기호 좌상단. 기본 꺼짐 |

## 2. 선택

| 입력 | 동작 |
|---|---|
| 좌클릭-드래그 | 사각형 안의 아군 유닛 전부 (자유 선택). 아군 유닛이 없으면 아군 건물 1개 |
| `Alt` + 드래그 | 사각형에 한 기라도 걸린 **분대** 전원 |
| `Shift` + 드래그 | 사각형에 한 기라도 걸린 **중대** 전원 (선택에 추가) |
| 좌클릭 | 유닛 한 기 선택 (빈 곳 클릭 · `Esc` 로 해제) |
| `Shift` + 클릭 | 선택에 추가 · 해제 (선택이 아군 유닛뿐일 때) |
| 더블클릭 (편제가 있는 아군 유닛) | **분대 → 중대 → 대대 → 분대** 순환 선택 (`Shift` 를 누르면 기존 선택에 더함) |
| 더블클릭 (편제가 없는 유닛) · `Ctrl` + 클릭 | 화면 안의 같은 종류 아군 유닛 전부 |
| 분대 칩 클릭 (중대 카드 안) | 그 분대 선택 (`Shift` = 추가 · 이미 다 골랐으면 해제) |
| 중대 카드 클릭 | 그 중대 선택 (`Shift` = 추가 · 이미 다 골랐으면 해제) |
| 빈 곳 클릭 | 선택 해제 (`Shift` 를 누르면 유지) |
| `Esc` | 명령 대기 중이면 취소, 아니면 선택 해제 |
| 숫자 `1`~`9` (숫자패드 포함) | 그 번호 **연대** 선택 (소속 대대 전부; 연대가 비었으면 같은 번호 대대). 같은 번호를 0.35초 안에 다시 누르면 카메라도 이동 (`Shift` + 숫자는 아무 동작 없음) |
| `Alt` + `1`~`9` | 그 번호 **대대** 선택 |
| `0` | 대대 목록 패널 열기 · 닫기 |

## 3. 기본 명령 (이동 · 공격 이동 · 정지 · 사수 · 돌격)

| 키 | 명령 | 동작 |
|---|---|---|
| `M` | 이동 | 지점을 찍으면 그 위치로 이동 (기본 대형 방향 유지) |
| `A` | 공격 (공격 이동) | 적을 찍으면 그 적을 공격. 땅을 찍으면 가는 길의 적과 교전하며 이동. 중립 대상도 `A` 로는 강제 공격 가능 |
| `S` | 정지 | 하던 명령을 멈춤 |
| `H` | 사수 | 그 자리를 지킴. 다른 유닛에게 밀리지 않음 |
| `C` | 돌격 (착검) | 적(또는 지점)을 향해 30% 빠르게 달려가 근접전. 돌격 중에는 사격하지 않음. 적이 2칸 안이면 자동 돌격. 여러 병과를 섞어 골라도 돌격 가능한 병사가 하나라도 있으면 버튼 · 단축키가 동작 — 근접 무기가 있는 병사만 돌격하고, 기관총 · 포 · 수레 등은 그 자리 **사수** (엄호 사격, N36) |
| `Q` | 속보 | 스태미나를 써서 걷기보다 15% 빠르게 이동 (돌격보다 느림) |

플레이어 직접 명령의 출발 지연 (반응 0~2틱 + 지휘 계통 지연) 은 고른 인원에 따라 줄어든다 — 1명 ×0.25 · 분대 (12) ×0.3 · 소대 (40) ×0.5 · 중대 (150) ×0.8 · 대대 (500+) ×1 (지금 수준), 사이는 선형 (`balance.json` `command.playerSelSizes/playerSelMul`, N37). AI 명령은 ×1.

**우클릭** (선택 유닛 대상, 명령 대기 중이 아닐 때):
- 적을 우클릭 → 공격 (무기 있는 유닛). 비전투 유닛은 따라 이동
- 땅을 우클릭 → 이동
- 우클릭-드래그 → **전선 명령**: 드래그 선의 중점으로 이동, 폭은 드래그 길이, 방향은 드래그 선에 수직이고 선택 무게중심에서 먼 쪽 (대형은 기본 대형 사용)

**명령 대기**: `M` · `A` · `Q` · `C` · `X` · `T` 는 누른 뒤 지점(또는 적)을 좌클릭해야 실행된다. 대기 중 우클릭 · `Esc` 로 취소.

`Enter` 는 명령 입력창(콘솔)을 연다 (§9).

## 4. 명령 카드

화면 아래 카드에 현재 선택에 맞는 명령이 뜬다. 카드 위치는 3×3 격자이며, 단축키는 카드의 글자와 같다. `Ctrl` 을 누른 채로는 카드 단축키가 동작하지 않는다.

**탭**: `Tab` 으로 **명령 ↔ 전투** 탭 전환 (또는 탭 버튼 클릭). 관전 중에는 `Tab` 이 관전 패널 토글이다.

### 4-1. 단축키 표

| 키 | 명령 | 카드 위치 (열, 행) | 표시 조건 |
|---|---|---|---|
| `M` | 이동 | (0, 0) | 전원 |
| `S` | 정지 | (1, 0) | 전원 |
| `A` | 공격 | (2, 0) | 무기가 있는 유닛이 하나라도 |
| `J` | 집결 지점 | (2, 0) 기본 (칸이 차면 둘째 쪽) | 중대 소속 유닛 선택 시. 단축키는 어느 탭 · 어느 쪽에서나 (전역) |
| `Q` | 속보 | (0, 1) | 전원 보병 (기병 제외) |
| `H` | 사수 | (1, 1) | 전원 |
| `X` | 수류탄 | (2, 1) | 전원 수류탄 보유 (돌격보병) |
| `E` | 자율 정찰 | (2, 1) 기본 | 전원 정찰병 |
| `O` | 포격 종류 (지속 → 준비 → 이동탄막 → 연막 순환) | (2, 1) 기본 | 곡사 · 방열 포가 있을 때 |
| `T` | 지점 포격 | (0, 2) 기본 | 전원 방열형 포 + 곡사 또는 범위 무기 |
| `F` | 돌격 사격 (중대 토글) | (0, 2) 기본 | 보병 중대 소속 유닛이 있을 때 |
| `D` | 하마 · 승마 토글 | (0, 2) 기본 | 전원 기병 (장교 제외) |
| `K` | 사격 통제 (자유 → 금지 → 응사만) | (1, 2) 기본 | 무장 유닛이 있을 때 |
| `V` | 돌격만 (기병 토글) | (1, 2) 기본 | 전원 기병 |
| `L` | 대열 정비 | (1, 2), 차 있으면 (2, 1) | 중대 소속 유닛이 하나라도 |
| `C` | 돌격 (착검) | (2, 2) | 근접 무기가 하나라도 (못 하는 병사는 사수, N36) |
| `W` | 참호 돌격 | 첫 빈 칸 (없으면 카드에 안 뜸) | 중대 선택 시 (참호 돌격 설정이 켜진 경우). 칸이 없어도 어느 탭에서나 전역 키로 동작 |
| `G` | 중대 병합 (카드 아님) | — | 중대가 선택돼 있으면 (§5) |

**둘째 쪽** (cmdcard, 2026-10-21): 한 선택에서 버튼이 9칸을 넘으면 (예: 보병 중대 + 곡사포) 넘친 버튼이 사라지지 않고 둘째 쪽으로 간다. 첫 쪽 마지막 칸 = "더 보기", 둘째 쪽 마지막 칸 (2, 2) = "처음으로" (클릭 전용, 단축키 없음). 모든 쪽의 단축키는 지금 보이는 쪽과 상관없이 동작한다. 새 선택 · 탭 전환 시 첫 쪽으로 돌아온다. `J` · `W` 는 전역 키라 쪽과 무관.

수류탄은 `X` 키 (2026-10-19 `G` 에서 이동; 중대 병합 `G` 와의 충돌 해소 — N15 항목 1). X 는 전투 · 배치 · 콘솔(글자 입력) · 카드 어디서도 다른 용도로 쓰이지 않음 확인.

**`L` 대열 정비** (gapfill, 2026-10-19): 고른 유닛이 속한 **중대 전체** (분대만 골라도 그 중대) 가 지금 빈자리를 메우고 자리를 다시 잡는다 — 교전 중에도. 명령은 20초 동안 유효 (`combat.closeWindowSec`): 슬롯에서 1칸 (`closeSlack`) 넘게 벗어난 대기 병사가 곧장 걸어서 (이동 명령) 자리로 가고, 교전 중 (표적 · 5초 안 사격) 인 병사는 숙련에 따라 — 신병 (계급 0~1) 은 곧장, 정규 (2~3) 는 50% 곧장 · 아니면 6초 뒤, 노병 (4+) 은 15% 곧장 · 아니면 12초 뒤 (교전이 끝나면 바로). 참호 안 · 참호 자리 병사, 사수 · 이동 · 돌격 중 병사는 그대로. 행군 중 (깃발 이동) · 전술 틀 행동 중에는 끝난 뒤에 (유효 시간 안). 단축키 `L` 은 명령 탭 · 전투 탭 둘 다 동작 (다른 키와 겹치지 않음 — 미션 배치 단계의 `R` 회전과도 다름). 장교도 교전 중 대열이 크게 흐트러지면 스스로 같은 명령을 내린다 (ENGINE_NOTES 'gapfill').

**`F` 돌격 사격**: 중대 단위 토글 (기본 꺼짐). 켜면 공격 이동 중 사거리 안에 적이 보일 때 장교가 판단해 중대 전체가 천천히 걸으며 사격한다. 일반 이동 · 후퇴 중에는 하지 않는다.

### 4-2. 유닛 종류별 명령 요약

| 유닛 | 카드에 뜨는 명령 |
|---|---|
| 일반 보병 | `M` `S` `A` `Q` `H` `C` `F` (+ 중대 소속이면 `L` · `J`, 무장이면 `K`, 설정 켜짐이면 `W`) |
| 돌격보병 | 위 + `X` (수류탄) |
| 정찰병 | 보병 명령 + `E` (자율 정찰) |
| 기병 | `M` `S` `A` `H` `V` `K` (+ `C` 근접 무기 보유 시, `D` 장교 제외, 중대 소속이면 `L` · `J`). `Q`(속보)는 기병 제외 |
| 방열형 포 (보병포 · 야전포 · 곡사포) | `M` `S` `A` `H` `K` `T` (지점 포격) · `O` (포격 종류) |
| 전차 · 장갑차 · 수송 차량 | **(확인 필요)** — 이번 점검에서 정리하지 않음. 카드는 `Available` 조건을 따름 (`src/Core/Commands.cs`) |

카드는 **선택한 전원이 조건을 만족할 때만** 뜬다 (공격만 예외로 한 기라도 무기가 있으면 뜸). 예: 보병과 포를 같이 고르면 `Q` 는 안 뜬다.

### 4-3. 전투 탭

대형 버튼은 단축키 없이 클릭 전용 (대열 정비 `L` 만 예외). 고른 중대가 있으면 그 중대들의 대형, 없으면 기본 대형을 바꾼다.

| 버튼 | 동작 |
|---|---|
| 대열 정비 (`L`, 칸 (0, 0)) | 중대 소속 유닛을 골랐을 때만. 명령 탭의 `L` 과 같음 (이 탭에서 단축키가 있는 유일한 버튼) |
| 자유 | 대형 없음 (`Free`). 고른 중대가 있어도 기본 대형만 자유로 바뀐다 |
| 산개 | 산개 대형 (고른 중대 · 기본 대형) |
| 더 보기 | 횡대 → 종대 → 쐐기 → 밀집 → 횡대 순환 |

## 5. 편제 (중대 · 대대)

용어: **분대** (유닛 묶음, 중대 카드의 칩) → **중대** (최대 100명, 카드 한 장) → **대대** (최대 10개 중대, 오른쪽 막대 한 칸). 대대에는 번호 1~9 를 붙인다.

| 입력 · 단추 | 동작 |
|---|---|
| `Ctrl` + `Alt` + `1`~`9` | 지금 선택한 아군으로 새 중대를 편성해 대대 n 에 넣음 (T08: 예전 `Alt`+숫자에서 이동). 대대가 가득 찼으면 안내만 뜬다 |
| `Ctrl` + `Shift` + `1`~`9` | 현재 대대를 연대 n 에 편입 (연대 = 대대 번호 기본 (n-1)/3+1, 편입 기록은 화면 상태 — 저장 안 됨, 설계 제안 참고) |
| `Ctrl` + `1`~`9` | 현재 대대의 번호를 n 으로 바꿈 (다른 대대가 이미 쓰는 번호면 서로 바뀜). "현재 대대" = 선택이 정확히 한 대대의 전 중대이거나 마지막으로 부른 대대 안 |
| `1`~`9` | 그 번호 연대 선택 (`Alt`+숫자 = 대대). 같은 번호를 0.35초 안에 다시 누르면 카메라도 이동 |
| `0` | 대대 목록 패널 열기 · 닫기 (목록에서 대대 · 중대 클릭으로 선택) |
| `G` · [병합] 단추 | 선택한 중대들을 한 대대로 묶음 (새 대대) |
| 중대 카드 드래그 → 대대 칸 | 그 대대로 편입 (대대가 가득 찼으면 안내) |
| 중대 카드 드래그 → 대대 막대 빈 곳 · 목록 패널 | 대대에서 분리 |
| 중대 카드 [분할] | 2명 이상인 중대를 나눔 **(확인 필요: 나뉜 뒤 구성 규칙)** |
| 중대 카드 [해산] | 중대를 해체 **(확인 필요: 병력의 처리)** |

## 6. 대형 · 전술 틀 · 역할

### 6-1. 대형 종류

자유 (Free) · 횡대 (Line) · 종대 (Column) · 쐐기 (Wedge) · 밀집 (Box) · 산개 (Spread) · 좌 · 우 사선 (Echelon, **기병 중대 · 분대만**).

### 6-2. 어디서 바꾸나

| 대상 | 입력 | 순환 |
|---|---|---|
| 기본 대형 (대대 막대 맨 앞 칸 "기본") | 좌클릭 | 자유 → 횡대 → 종대 → 쐐기 → 밀집 → 산개 → 자유 |
| 기본 대형의 병과 배치 | 우클릭 (같은 칸) | 혼합 → 기갑 앞 · 보병 뒤 → 보병 앞 · 기갑 뒤 → 혼합 |
| 선택 중대 | `Ctrl` + `F` | 횡대 → 종대 → 쐐기 → 밀집 → 산개 → 횡대 (기병 중대는 산개 다음 좌 · 우 사선). 고른 중대가 없으면 기본 대형 |
| 선택 대대의 대형 | `Ctrl` + `Shift` + `F` | 선택 대대가 있으면 대대 대형 순환 (아래), 없으면 기본 대형의 병과 배치 순서 |
| 대대 대형 | 대대 막대의 대대 칸 좌클릭 | 횡대 → 종대 → 사다리 → 2선+예비 → **파상** → 횡대 |
| 중대 카드 [대형] | 좌클릭 | 중대 대형 순환 (`Ctrl`+`F` 와 같음) |
| 분대 대형 (분대 1개만 선택) | 중대 카드 [분대] | 자동 → 밀집 → 산개 → 종대 → 횡대 → 쐐기 → 자동 (기병은 쐐기 다음 좌 · 우 사선) |

### 6-3. 전술 틀 · 역할

- **전술 틀** (중대 카드 [전술]): 틀 없음 → 화력-기동 → 좌측 우회 → 우측 우회 → 종심 방어 → 포병 대형 → 돌격 → 틀 없음.
- **역할** (분대 1개만 선택, 중대 카드 [역할]): 자동 → 화력조 → 사격조 → 기동조 → 지원 → 지휘 · 정찰 → 자동.

콘솔로 같은 것을 설정할 수 있다 (선택한 중대 대상, §9): `ftac`, `fco`, `fsq`, `fbat`, `fmove`.

## 7. 포병 (방열 · 지점 포격 · 사계)

- **방열**: 방열형 포 (보병포 2초 · 야전포 4초 · 곡사포 6초, 데이터 `setupTime`) 는 **쏘려 할 때 자동으로 방열**한다. 방열 완료 전에는 쏘지 않는다. 방열 중 · 방열 상태에서는 이동할 수 없고, 이동 명령을 받으면 먼저 철수한다 (철수 시간 `packTime` 1.5 · 3 · 4초). 수동 방열 명령은 없다.
- **사계**: 방열할 때 정한 중심 ± 절반 (데이터 `traverseArc`) 안만 쏜다. 밖의 표적은 철수 → 회전 → 재방열 순서로 대응한다. 사계 값은 `assets/data/balance.json` 참고.
- **지점 포격 (`T`)**: 지점을 찍으면 관측자 없이도 그 지점으로 계속 포격한다 (퍼짐 1.5배). 사거리 밖 · 최소 사거리 안은 불가. 직사포는 사선이 필요하다. 정지 · 다른 명령 · 탄약 소진 시 끝난다.
- 방열형 유닛 중 중기관총 계열 (`heavy_machinegunner` · `heavy_maxim`) 과 `heavy_at_rifleman` 도 `setupTime` 3 이 있으나, 지점 포격 표시 조건 (곡사 또는 범위 무기) 에 맞는지는 **(확인 필요)**.

## 8. 정찰병

- 정찰병 (`scout`, `infantry_scout`) 은 시야가 1.5배 (`scoutSightMul`).
- **자율 정찰 (`E`)**: 켜면 중대가 움직일 때 스스로 6~10칸 앞서 가 관측한다 (곡사포 관측 포함). 제압 · 부상 · 적 발견 5초 뒤, 또는 너무 멀어지면 장교에게 돌아온다.
- 직접 명령을 내리면 자율 정찰이 꺼진다. 다시 `E` 를 누르거나 소속 중대가 새 명령을 받으면 켜진다.

## 12. 충돌 (한 키에 여러 동작)

점검 결과: **같은 상황에서 한 키에 두 동작이 걸린 곳은 없다.** 아래는 같은 키를 상황 · 수정키로 나눠 쓰는 곳이다.

- `Enter`: 명령 콘솔 열기 (본 게임) · 미션 배치 시작 (배치 단계) · 게임 끝 화면에서 재시작 · 콘솔 안에서는 실행.
- `Esc`: 명령 대기 취소 → 선택 해제 순서. 콘솔 · 메인 메뉴에서는 각자 닫기.
- `F`: 돌격 사격 카드 (수정키 없음) · `Ctrl`+`F` 진형 순환 · `Ctrl`+`Shift`+`F` 병과 배치. 카드 단축키는 `Ctrl` 이 눌리면 막힌다.
- `G`: 중대 병합 · `Ctrl`+`G` 격자 표시 (수정키로 분리).
- `W`: 참호 돌격 — 카드 칸이 있으면 카드, 없으면 전역 키. 같은 동작이 한 번만 실행된다 (`pressedCard`).
- `L`: 대열 정비 — 명령 탭 · 전투 탭 둘 다 (같은 동작).
- `Tab`: 관전 중 관전 패널 토글 · 그 외 명령 ↔ 전투 탭 전환 (상호 배타).
- `1`~`9`: 대대 선택 · `Ctrl`+숫자 번호 바꾸기 · `Alt`+숫자 중대 편성 · 관전 중 시점 전환. 수정키 · 모드로 분리. `Shift`+숫자는 대대 선택만 막고 다른 동작은 없다.
- `F5`: 교전 테스트 중에만 재시작 (그 밖에는 무동작).
- 카드 칸 (2, 1): `X` · `E` · `O` 의 기본 칸이 같다 → 나중 버튼이 첫 빈 칸으로 이동, 칸이 끝까지 차면 둘째 쪽 (키는 그대로, 키 충돌 아님).
- 코드 점검 (cmdcard): 카드 단축키 `M S A Q H X T V D E C F K L O W J` · 전역 `B I N G R Space Tab [ ] + - F3 F5 F6 F7 0~9` 사이에 같은 상황 중복 없음. 게임 안 `keys` 콘솔 명령이 이 표 (`src/UI/Bindings.cs`) 를 그대로 출력한다.
