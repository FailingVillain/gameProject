## MAP-B 안동 일대 (large, 1200x1200)

생성: `python tools/c1e1/gen_map_b.py [W] [H]` (기본 1200 1200, 같은 인자 = 같은 파일; 모든 좌표는 가로세로 비율이라 다른 크기도 같은 모양). 출력 `assets/maps/c1e1_map_b.json`.
검증: `--check` (부속지-시가지 분리 간격 >= 8칸, 부속지 열린 칸이 하나의 연결 영역, 부속지 안 물 0, 시작 위치에서 적 지휘소·부속지까지 도보 연결), `--areas` (아래 표 출력), `--sheet --out X.png` (전체 + 구역 시트).
방향: 북 = y 작음, 강(압록강) = 동쪽. 좌표는 타일, 사각형 = x y w h. 구역 이름은 계획서 §3 약속.
시작: 플레이어 `b_sw_start` 중심, 적 `b_hq` 상단 광장. (미션 JSON 이 areas/forces 를 정한다; 지도 JSON 에는 구역이 없고 이 표가 원본.)

### 부속지 (b_annex) 시험 값 (TC-G 가 읽을 좌표)
- 사각형 x=792 y=264 w=216 h=192 (타일 [792,1008) x [264,456)). 시가지 `b_city` 와 24칸 떨어진 풀밭 띠로 분리, 어느 다른 구역과도 겹치지 않음. 철로 없음 (R9 대체안) — 격자 도로 + 가옥 블록 + 둘레 흙길 경계선 (경계 바깥 1칸 ~ 안쪽 1칸).
- `--check` 가 연결·분리를 시험한다 (위 검증). MapFile 로드는 `--map c1e1_map_b --shot` 으로 확인.

### 지형 선택 (명세 초안 대비, 사용자 구술로 수정 가능)
- 시가지: 가옥 블록을 난수(고정 시드)로 불규칙 배치 + 십자 대로 2개 (가옥은 통과 불가라 대로가 연결을 보장). 목재 야적장 = rubble (엔진에 목재 지형 없음).
- 부두: 강변을 직선으로 펴고(잔교 모래 돌출 + 창고 가옥) 시가 중앙로가 부두로 이어짐.
- 외곽 참호: 북 참호(y~414) + 서 참호(x~342) L자, 철조망(통과 불가) 앞줄. 도로 차단 지점(`b_road_block`)에서만 도로가 끊김 → 정면 돌파 지점. 철조망 끝(북선 동단 x=720, 서선 남단 y=864)을 돌아 우회 가능.
- 진강산: 서북 독립 구릉(high 원 반지름 84), 야포 갱 4 + 관측호(trench), 바위 2. 포대 유닛 배치는 미션 JSON 몫.
- 부속지 위치 = 시가지 북동쪽, 강 동편 부두와 반대 (명세에 위치 없음 → 임의; DECISIONS_PENDING 에 질문).
- SK1 우회로(`b_flank_path`) 위치·모양도 명세에 없어 서쪽 가장자리 북상 + 북부 평야 쪽 동진으로 가정 (질문 등록).
