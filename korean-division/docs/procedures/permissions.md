# 권한 · 자율 진행
> 요약: 권한 프롬프트가 날 명령은 시도하지 않고 DECISIONS_PENDING 에 한 줄 적고 속행.

- 대상: 폴더/파일 삭제, 이미지 이름 프로세스 종료(`taskkill /IM`), 저장소 밖 쓰기, push 등 프롬프트/거부가 날 만한 명령.
- 처리: 시도하지 않는다. 거부된 명령을 다른 도구로 우회하지 않는다. `docs/DECISIONS_PENDING.md` 끝에 `- [에이전트/작업] 필요한 결정/권한: ...` 한 줄(= ops/DECISIONS 후보, 코디네이터가 ID 부여해 옮김) 후 남은 일을 계속한다.
- 사용자 결정이 필요한 질문도 같은 파일에 한 줄로 모은다(여러 번 묻지 않음). 보고에는 "결정 N건 DECISIONS_PENDING 에 기록"만 적는다.
- 명령은 한 호출에 하나(잠금 + 병합 + 빌드 연결 금지: 권한 검사기가 거부).
- 비밀 파일(keys.json 등)은 Gemini 에 첨부하지 않는다.
