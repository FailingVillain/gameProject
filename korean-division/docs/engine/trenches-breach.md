# Engine notes - trenches-breach (trench occupation, trench assault, breach (smoke, barbed wire)) (엔진 노트 - trenches-breach (참호 점유·참호 돌격·돌파(연막·철조망))) [split from ENGINE_NOTES.md 2026-10-23, body verbatim]

### Trench auto-occupation and shell craters (참호 자동 점유 · 포탄 구덩이) (2026-10-19, `src/Core/Trenches.cs` · `Render/MapRenderer.Edits.cs`, test `Tests/TrenchSelfTest.cs` = `KD_SELFTEST_ONLY=trench`)
- **Construction removed (user decision 2026-10-19)**: trench-line command (T) · work · per-tile progress · personal trench · tool swinging · TrenchOverlay deleted. A trench = only the `trench` terrain in map/mission `paint` (hit ×`terrain.trenchHit` 0.6 · suppression ×`trenchSuppress` 0.5, for anyone).
- **Trench cluster** = trench tiles connected in 4 directions (`TrenchCompAt`, a derived value recomputed when the terrain hash changes - not saved). **Spot** = tile × 4 + k, `terrain.trenchPerTile` (2) per tile, side by side along the trench direction (`TrenchSpotPos`). The occupancy table (spot -> unit) is regathered from the unit list every tick.
- **Unit state** (`Unit`, [SnapExt], end of SUPL · checksum): `TrenchSpot` (assigned spot, including while on the way) · `InTrench` (entered and holding) · `TrenchIgnore` (cluster not to be occupied en route during this order). Eligible = `UnitDef.CanOccupyTrench` (infantry; cavalry · scouts excluded).
- **En-route occupation** (`UpdateTrenchCapture`, after movement in UpdateUnitCore): walking with Move · AttackMove · not charging · no spot · standing tile is a trench (cluster ≠ TrenchIgnore) -> takes the nearest free spot within `trenchCaptureRadius` (1.5) of the same cluster and goes there as a 1-man movement group. If no free spot, passes through.
- **Arrival** (`ArriveGroup` -> `TrenchOnArrive`): within 0.45 of the assigned spot -> `EnterTrench` (Order Hold); if not reached, the spot is released; if it arrived on a trench tile, it finds a free spot and enters (without the ignored-cluster rule).
- **Slot snapping** (`SnapSlotsToTrenches`, at command execution): company flag move final slot (`StartCompanyMove` FinalOff) · old formation slot (`ApplyFormation` plan.Off) · the target of a one-man move without formation - if a free spot is within `trenchSnapRadius` (2), it goes to that spot - greedy assignment in (distance², unit Id, spot) order, with the spot the commanded unit currently holds counted as free. The spot is `ClaimSnapped` after ResetOrder. A soldier going to a claimed spot is not caught by other trenches on the way.
- **Release**: every new command (`ResetOrder` -> `LeaveTrench`) = spot released + TrenchIgnore = the cluster of the spot left (or the tile stood on). A **Hold command** keeps the spot if inside a trench or on the way to a spot (within 2.5 tiles) (`HoldKeepsTrench`). Overlap resolution: allies holding spots do not push each other (`SepFlags` 32).
- **Tactical AI**: defense (`LineDefend`) = if there is a trench within 6 tiles of the defense position, with profile `trench` probability (company hash) it attack-moves to that trench tile as its position (even if close, once - the slot snaps to the spot), cumulative `TrenchMoves`. No personal trench command.
- **Shell craters**: `Explode` (shared by indirect and direct fire explosions, the tick the shell lands after flight) -> `TryCrater`: if the landing tile is grass · dirt · sand (no facility occupying) and `Roll(shooterId, 0x0C4A7E5) < weapon.craterChance` then `Crater`. Values `terrain.craterMove/Hit/Suppress`, `TerrainType.Crater` (byte 10), map json `"crater"`.
- **One place for terrain change** `World.MutateTerrain` (only between terrains with the same passability -> irrelevant to pathfinding): `GameMap.EditTerrain` (Set + render edit record, not saved) + `Fog.TerrainChanged`. Rendering = `MapRenderer.ApplyEdits` rebakes ±1 chunk around the edited tile. Trench tile art = theme `terrain.trench_line_<name>` (mask N1 · E2 · S4 · W8).
## Trench assault (참호 돌격) (N32, 2026-10-20, branch `n32`, `src/Core/TrenchAssault.cs` · `src/AI/Tactical/TacticalAi.TrenchAssault.cs`)
- User approval (night of 2026-10-20): trench assault doctrine = player command + tactical AI, same sequence. Original spec = HANDOFF N32. Smoke · wire cutting · collapse · rout are outside this bundle (only the places for `smokeHook` · `wireCutHook`).
- Command `TrenchAssaultCommand(Faction, Companies[], Target, On, Ai)` (json `trenchassault`, Replay 16) - snapped to within `snapRadius` of a trench tile, if refused no command is made. Cancel = On false, or another command calling that company's units (`TaCancelByOrder`, very start of ExecuteInner). Per company; if a battalion is chosen its companies each follow the same sequence (no synchronization among them - proposal).
- State `Company.TA` (`TrenchAssaultState`: Stage · Sub · Result · Flags · Target · Dir · FirePoint · ticks · BoundGroup) - `WriteTrenchAssault` at the end of ORG_, checksum, Audit, Snapshot 44. The trench cluster · both ends · rifle/light machine gun classification are recomputed from the map · units at every decision (not saved). Decision interval `decideSec` 0.5 s (`StepTrenchAssaults`, before StepTactics; a company in assault skips StepTactics · vacancy checks · formation upkeep).
- 1 Suppress: outside `farDist` it assembles -> light machine guns (`tactics.roles.byWeapon` = fire) go to a position at range × `gunStandFrac`, rifles cover standing, artillery calls `GroundFireCommand` internally (`useGroundFire`; for tactical AI factions it conflicts with the artillery AI, so `aiGroundFire` is off by default). After assembly · reaching positions, for `prepMinSec` ~ `prepMaxSec`, if among visible defenders (in the trench · within 2 tiles) the ratio that is prone · pinned · suppression ≥ `suppGoal` is ≥ `suppFrac`, go to the next stage.
- 2 Approach: the rifle squad is split into two groups by odd/even number (by Id odd/even if there is only one squad) bounding alternately `boundLength` tiles (cover tiles `DrillCover`, normal movement = move without firing, the other group fires from a hold), swap when `boundMaxSec` is exceeded. When the average distance to the trench is within `boundEndDist` (12 tiles - the original spec "~30 tiles" is outside rifle range 24, so bounding is meaningless and the rush becomes the whole fire zone; measurement B 1/5 -> 5/5, the original value can be compared with the `TA30` variant), everyone rushes at a quick march (to a point at grenade range × `rushStandFrac`). Bombardment, once rifles are within `liftDist`, goes `creepLead` tiles beyond the trench (creeping barrage).
- 3 Breakthrough: rifles within grenade range at `breakFrac` or more (or `approachMaxSec`) -> grenades `volleys` times (aimed at the nearest trench tile) -> after `fuseWaitSec` `ExecCharge` (including bayonet fixing N57, skipping the charge-permission gate - the order has already confirmed suppression) `chargeThrough` tiles beyond the trench. When `enterFrac` have entered the trench, go to the next stage.
- 4 Clearing: the two rifle groups attack-move to both ends of the trench axis (column formation), light machine guns `endHoldBack` tiles inside both ends. If no visible enemy infantry is within `clearRadius` around the trench for `clearConfirmSec`, go to the next stage (if `clearMaxSec` is exceeded, continues only while 3 or more are near the trench).
- 5 Securing: `ExecOccupyPositions` (center = the trench tile near the rifle center of mass, dir = attack direction = opposite of the direction toward the first enemy side -> trench front spots on the opposite side), successful end after `consolidateSec`. Failure (rifles wiped out · `maxTotalSec` · breakthrough failed) = hold in place, the AI does not retry for `cooldownSec`.
- AI: in `CompanyThink` an attack-task rifle company (strength ≥ `aiMinMen`, visible trench defenders ≥ `aiMinDefenders`, strength ≥ defenders × `aiMinOdds`, distance `aiMinDist` ~ `aiTriggerDist`) issues the same command. Profile `tactics.trenchAssault` (default true), measurement overlap profile `notrenchassault` (`--ai tactical:notrenchassault`). Retreat judgement during assault is unchanged (the retreat command cancels the sequence).
- Replay determinism: commands issued by the AI carry the `Ai` flag in the command (there is no AI controller in playback, so if the sim looked at the faction's `IsAi` it would diverge - the mission replay test caught this). The AI is not used on companies in a maneuver plan (stage 3A fixed · maneuver echelon) · river crossing · counterattack.
- Statistics (`MoveStats`): TaStarts/Done/Fail/Cancel · TaBounds · TaGrenades · TaCharges · TaConsolidations · TaAiStarts · TaStageEntered[]. Test `KD_SELFTEST_ONLY=n32` (`N32SelfTest`).
- Hotkey selection: **W** (does not overlap used keys M S A Q H X T V E C G I N F L R Z B K D, Tab, Space, F3/5/6/7/10). If the command tab has an empty slot, a card button; if full like the infantry company, the combat tab (2,0) button + W on any tab.

## Trench breach bundle (참호 돌파 묶음) (N59 smoke · wire cutting, N60 light mortar, N65 smoke grenade - 2026-10-22, `src/Core/Breach.cs`)
- Smoke = `World.Smokes` (circular, position · size fixed, no wind · spreading, disappears at `EndTick`). If the total length of the sight line a->b passing through smoke > `breach.smokeSeeDepth` (1 tile) it is blocked (`World.SmokeBlocks`, scalar arithmetic). Applied to: direct-fire line `World.HasFiringLine` · auto target `FindTarget` · `CavReact` · spotter `SeenBySpotter` · fog stamping (`FogOfWar.StampSmoky` - checks tile by tile only observers whose vision circle overlaps smoke, the same tile · same radius once). `GameMap.HasFiringLine` (terrain only) · the tactical AI terrain score do not know smoke (cache determinism).
- Smoke grenade: `unit.smokeGrenades` (assault infantry 1), `ThrowSmokeCommand` (hotkey Y), range · fuse · scatter = grenade, radius 2.5 · 30 seconds. Recovery = same clock after grenades are full.
- Smoke shell: only guns with `weapon.smokeRadius` (howitzer 5 · mortar 2.5~3.5) get the point-bombardment 'smoke' kind (ends after `breach.smokeRounds` 3 rounds, duration 45 s). If `ShellFlight.Smoke` · `GrenadeBlast.Smoke`, smoke instead of damage on landing.
- Wire cutting: `unit.wireCutter` (assault infantry), `CutWireCommand` (hotkey U) - wire tiles within `wireCutSearch` tiles around the point are taken one person at a time in nearest order, going to an adjacent tile (up/down/left/right first) and in a hold posture for `wireCutSec` (4 s) -> tile = dirt (`GameMap.OpenWire`: Version · ChangeLog -> pathfinding refresh). A new command (`ResetOrder`) = cancel. Progress bar = `ProgressRing`.
- Light mortar (range 36, indirect fire without a spotter - enemies its own faction sees): Korea `heavy_mortar_korean` (경 미넨베르퍼) · Japan `heavy_mortar_japanese` (척탄통, 1 man) · others `heavy_mortar` (Stokes, 봉천 · Russia). Values = draft (before balance approval), art = infantry gun alias (artAs).
- Save = `WriteBreach` at the end of CMB2 (FormatVersion 53, Replay 20), checksum `HashBreach`, replay v19. Test `KD_SELFTEST_ONLY=breach`. `smokeHook` · `wireCutHook` of the trench assault sequence (N32) are still only placeholders (AI use is the next stage).
