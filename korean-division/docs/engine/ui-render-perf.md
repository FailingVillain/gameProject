# Engine notes - ui-render-perf (unit sheet LOD · UI icons · branch markers · spatial hash · civilian house styles) [split from ENGINE_NOTES.md 2026-10-23, body verbatim] (엔진 노트 - ui-render-perf (유닛 시트 LOD·UI 아이콘·병종 마커·공간 해시·민가 양식))

### Unit sheet LOD (유닛 시트 LOD) (2026-10-19, `src/Render/LodSprite.cs`, theme `assets/themes/kd1920`)
- A theme entry with `"layouts": [main, @64, @32 layouts]` + `"scale"` (world px per 1 px of LOD0, 0.25 → infantry 32×40) is the new format. Frame size · anchor · sheet split · hull `turret.mount` are all read from json (the 1.5x vehicle re-render 288²/240² also fits as is). `"inherit": "ww2"` = missing keys · names · terrain come from the parent theme.
- LOD choice: if the on-screen cell width (LOD0 width × scale × zoom) is at most the smaller LOD width × `lodUpscale`(1.15), use the smaller LOD. Infantry: zoom <1.15 = @32, <2.3 = @64, above that = 128. Zoom <0.5 = dot (`UnitRenderer.DotZoom`). MaxZoom is 4.0 (Config.MaxZoom), so the 128 sheet applies at zoom >= 2.3.
- Atlas (`src/Render/LodAtlas.cs`, 2026-10-19 art-memory): **transparent margins are trimmed from each cell** before packing (keeps a 1px transparent border + 1px gap between cells - rectangle edges do not overlap opaque boundaries, so rasterization is pixel-identical to before trimming). With the trimmed offset `COX/COY` the anchor stays relative to the cell, and when mirrored `FrameW − COX − CW`. Cells the animation mapping does not use (outside `LodSprite.UsedAnimNames` · `UsedFrameNames`: spare, go_prone) are left out - **if you use a new animation name in UnitArt, also add it to `UsedAnimNames`**. Keys that are not `unit.` such as buildings · sheets without animation are packed whole.
  - **LOD 1 · 2** = a shared page per LOD number (one texture = one batch for the zoomed-out view), built at first draw from the kinds registered so far and kept resident (kinds registered later get additional pages).
  - **LOD 0** = a dedicated page per kind × faction variant, built when that kind is first drawn at maximum zoom. Evicted if not drawn for `KD_LOD_EVICT_SEC` (30) seconds, and when the resident total exceeds `KD_LOD0_BUDGET_MB` (768, raised from 256 on 2026-10-19 - uifuzz 30-second budget overrun evictions 65 → 0), evicts starting from those unused for over 0.5 seconds (if visible ones alone exceed it, left as is).
  - The smallest LOD is synchronous on first draw, the rest go to a worker thread (`Task.Run`: PNG read · team-color folding · trimming · shelf packing) → the main thread `PumpAll` (at the start of UnitRenderer.DrawUnits + at 6 ms intervals during drawing) creates the empty texture and uploads `KD_LOD_UPLOAD_MB` (6) at a time row by row with `glTexSubImage`. Until everything is uploaded, `LodDraw.Cell` draws with the next smaller ready LOD (`LodAtlas.Resolve`). `KD_LOD_SYNC=1` = everything synchronous (for comparison).
  - Measurement: log `[lod] L0 unit.x: ... MB (자르기 전 ... MB)` · `내림`, `LodAtlas.Summary()` (printed at the end of uifuzz: current · max per LOD, resident/pre-trim per kind, max upload frame ms), in-game console `fps` performance line ending `tex L0 a/256MB L1 b L2 c (peak)`.
  - Numbers (`--uifuzz 60`, all unit art): before: all LOD0 707 MB · LOD1 180 · LOD2 46 = 933 MB → after max 290 MB (LOD0 max 211 · LOD1 62 · LOD2 17), near the end 220 MB (13 LOD0 kinds evicted). LOD0 per kind examples: howitzer 50.6 → 22.8, field gun 32.0 → 13.4, infantry 19.9 → 9.5, tank turret 7.9 → 0.9 MB. Max upload frame ≈ 3 ms. Screenshots at zoom 1/2/4 = pixel-identical to the previous build (`KD_SHOT_NOINPUT=1` - ignores the real mouse · wheel during `--shot`).
  - Not done: RGBA4444 / DXT compression - the team marker is an exact alpha 254 and the art is point-filtered pixels, so the picture would change. Separating the team mask into a single channel was skipped because of the batching problem in the "Team color" item above.
- Team color (팀색): when `_team.png` (grayscale, alpha 0/255) is loaded it is folded into the base sheet - team pixel = (gray,gray,gray, alpha 254). `TeamShader` paints only alpha-254 pixels as vertex color (faction color) × gray. Reason for not keeping a separate R8 texture: the raylib batch drops the extra sampler (texture1) at every flush, so it would have to be rebound for every unit. If the shader fails, team pixels are gray.
- Shader switching: `TeamShader.Enter()` before LOD drawing, `Leave()` before old sheets · shapes · shadows (mixing breaks the batch that many times).
- **Headband (team layer) display rule** (머리띠 (팀 층) 표시 규칙) (2026-10-19, `UnitRenderer.HeadbandOn`): the team pixels of human art (LOD `Directional` · old directional sheet) are the faction color only in engagements where uniforms are confusing - on if a living hostile faction has the same art variant (`FactionArt.Variant`: between the same faction · factions with the same uniform, default = Korea), otherwise cloth color `Palette.BandHidden` is used as the vertex color (shader · batch unchanged). Vehicle markers are always the faction color. For checking `KD_HEADBAND=always|never`. If a re-import leaves only the headband in the team layer, it works as is.
- **Underfoot · selection display** (발밑 · 선택 표시) (2026-10-19): the faction-color circle under the feet is deleted (shadow only). Selection line = about 1 px on screen (`ring = 1.1/zoom`), and if my unit is in combat (alert state `SimView.Alerted`) the same line is orange (`Palette.SelectCombat`) - the outer orange ring is removed. Zoomed-out dots · minimap keep the faction color.
- Animation (`UnitArt.LodFrame`, display-only hash): charge = melee/melee_b (every melee attack) · charge (running) · officer sword_wave (right after a charge order), firing = aim/fire cells of fire_a/b/c (hash per shot), if suppression >= 0.5 and standing fire_prone (aim_prone/fire_prone), hit for 9 ticks = hit, walking = walk or walk_shoulder (unit · order-tick hash 33%, walk if no art), waiting = idle + occasional idle_alt / idle_lean. Death = one of death/death_b/death_c by unit id hash (`Corpses`, in the viewed direction). Vehicles: hull idle/move/dead, turret idle/fire (timetable)/dead.
- All-unit art (전 유닛 그림) (2026-10-19, art-import): crews · guns · cavalry · wagons work the same way (one sheet = crew + equipment, sheet `_1/_2` splits are already handled by layout `cells`). Faction variant = theme key `unit.<unit>@<japanese|fengtian|russian-white|russian-red>`, the faction comes from map `factions[].en` (`FactionArt`: russian→White army, soviet→Red army, others = default Korea, for checking `KD_ART_FACTIONS=japanese,fengtian`), missing variants use the default art. `UnitArt.LodFrame` additions: crew/gun (`deploy|unpack` · `pack` · `fire|fire_prone|fire_kneel` - cell chosen by deployment progress (`DeployProgress`), firing from the time of the shot, travel posture = idle or for guns the first unpack cell), march fire `walk_fire` (MarchFire · when a target exists), idle variant pool (`idle_alt/lean/rest/look/adjust/stretch/idle_3` 14%/4 seconds), `present_arms` after victory (officer `salute`), cavalry `gallop` (fast movement) · charge-impact stagger = `hit`, wagon `start` · `supply` (when cargo decreases) · `hit_b` · `destroyed` (death). Missing animations are skipped silently → when a re-render produces new motions they turn on with no code change.
- Re-import (2026-10-18 art4): new renders = team layer headband only, faction variant keys added for cavalry · sniper · infantry gun · field gun (`VARIANTS` is generated from `_VARIANT_BASES`, variants without a folder = howitzer skipped), hitch/unhitch added to `UsedAnimNames`. March-fire muzzle flash = `UnitArt.MarchFlash` + `UnitRenderer.DrawMarchFlash` (no flash in walk_fire, 4 ticks after firing). Faction badge icons = `tools/import_kd1920_badges.py` → `icon.badge.<korean|japanese|fengtian|russian|soviet>@<16|24|32|48|64>`, zoomed-out company marker `UnitSymbols.DrawBadge`.
- Import: `python tools/import_kd1920.py` (game-tools/korean-division-image-out → kd1920/units/<name>/, rewrites theme.json, the alias table is inside the script).

### Spatial hash · terrain-derived cache (공간 해시 · 지형 파생 캐시) (N16, 2026-10-19, `World.RebuildHash` · `GameMapTerrain.cs`, test `Tests/SpatialHashSelfTest.cs` = `KD_SELFTEST_ONLY=hash`)
- The spatial hash is `cellStart[c]` + `cellCount[c]` (the start value of an empty cell may be stale - always read as `start..start+count`, never `cellStart[c+1]`). Clears only the previously occupied cells `occCells` and radix-sorts only the occupied cells → cost O(units). Order = cells ascending · index within a cell descending (determinism · golden depend on it).
- Terrain derivation: forest depth · cell display are recomputed only when forest · house cells change (`terrainDirty`), the terrain hash only when the checksum asks (`terrainHashDirty`). Cache invalidation keys use `Map.TerrainVersion` (every terrain · high-ground change) · `Map.TrenchVersion` (trench cell change), and `TerrainHash` is not used as a key (it computes a whole-map hash on each query).
- `--mapload` output: `SECMAX` (per-section p99/max) · `WORST` (breakdown of the worst 5-tick section · GC · terrain edit count) · `TERRAIN` · `GC`.

### Max-zoom LOD0 omission audit (최대 확대 LOD0 누락 감사) (N19, 2026-10-19, test `Tests/LodAuditSelfTest.cs` = `KD_SELFTEST_ONLY=lodaudit`)
- Read-only audit: `UnitArt.ReachableFrames()` (every cell the art can produce) × 5 variants × 3 LOD levels × all direction rows are in `LodSprite.Used`, have a layout cell, and the sheet alpha is not empty + a sweep of the infantry · crew world. It runs by opening a hidden window (for old-format sheets). If you use a new animation name in UnitArt, also add it to `ReachableFrames`.
- `KD_LODMISS=1`: cells `LodDraw.Cell` could not draw (out of range · no LOD · empty cell) are printed once each to stderr as `[lodmiss]`. Empty cells are now drawn with another ready LOD instead (`LodAtlas.FindCell`).
- Environment variables for checking: `KD_SCENE_R` (mgaim ring radius), `KD_SHOT_FOLLOW=1` + `KD_SHOT_FOLLOW_KEY=<kind key>` (--shot camera on the center of mass of my units).

### UI bundle: grenade X · friendly-fire counter · squad status icons (UI 묶음: 수류탄 X · 아군 오사 계수 · 분대 상태 아이콘) (2026-10-19, branch `uiicons`)
- **Card slot conflict resolution** (N15-2): `Game.ResolveSlots` - if the same slot, the later button goes to the first empty slot (hotkeys unchanged). Test = slots · hotkeys unique across all 1~2 kind unit combinations.
- **Grenade = X** (`Commands.cs`; G is for company merge only, resolves N15 item 1). Confirmed that X has no other use in combat · deployment · console (text input) · cards. N15 item 2 is also resolved (below).
- **Friendly-fire counter = measurement-only side channel** (`MoveStats.FriendlyFire`, hits · kills · damage per weapon key). Reason for choosing it: the counter is not read by the sim, so it does not touch the checksum · save · FormatVersion (27) and the `--detcheck` golden is kept. Cost: it starts from 0 after loading a save (mission results are meaningful only within one game). Recording place = one spot `World.Damage(target, amount, source, weapon)` (attacker team == victim team or allied, weapon key = passed by the caller: rifle · shell fragments = weapon key, grenade = `grenade`, melee = `melee`, otherwise the attacker's weapon). Exposed through `MissionResults.FriendlyFire` (JSON) and the `[아군오사]` line of `--tactics-obs`. The engine filters same-team targets for fragments · grenades · machine-gun spray (`IsHostile`), so it is nearly 0 in normal state - only cases such as ground fire (T) placed on friendlies are caught.
- **Squad status icons** (분대 상태 아이콘) (`Render/SquadIcons.cs`, display only): priority pinned > suppressed > retreat > out of ammo > charge > no commander > trench occupation. Suppressed = squad average `SuppressionRatio` >= 0.35, charge · trench · ammo 0 = half or more, no commander = no living officer in the company and the squad leader is not an NCO, retreat = the tactical AI group of the company is in `Fallback` (player companies have no tactical AI so no retreat display yet - `Facts.Retreating` hook), pinned = the `Facts.Pinned` slot to be filled when the prone state appears. 7x7 dots are generated in code into one atlas, 1 draw per squad, state cached for 6 ticks. At zoom >= 0.5 friendly squads, at zoom < 0.5 (company badge range) only the selected squad. Toggle = `I` key · top button (`SquadIcons.Enabled`).

## T55s House style selection (T55s 민가 양식 선택) (render only)
`houseStyle` (map json / mission json, mission takes precedence; korean | manchu | mixed, omitted = the old 4 kinds) -> `HouseStyles.Assign` assigns pieces over the whole map in order in one pass (coordinate hash; if the same (key, baked B) is within 2 cells to the left/up, raise the salt and retry up to 3 times). Weights·tints·42-key registration = assets/data/house_styles.json (key = building_art.house.<prefix>NN, B variant = key+".b", missing keys skipped, if a class has none, fall back to the old keys). Mirroring = CellFit/Cell negative source width, tint = vertex color multiply in plain (default shader). The team shader does not multiply vertex color onto opaque pixels, so plain is required for tints. Ruined cell = 'ruined' / 'ruined_b' frames (frame 1 if absent). Snapshot·checksum·FormatVersion unchanged.
