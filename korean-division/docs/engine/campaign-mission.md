# Engine notes - campaign-mission (mission frame · static teams · campaign · force carry-over · battle autosave) [split from ENGINE_NOTES.md 2026-10-23, body verbatim] (엔진 노트 - campaign-mission (미션 틀·정적 팀·캠페인·병력 이월·전투 자동 저장))

### Static teams (정적 팀) (2026-10-19, replaces the diplomacy system, `src/Core/WorldTeams.cs`, test `Tests/TeamSelfTest.cs`)
- **Map format**: `"factions": [ { "name": "한국", "team": 1 }, { "name": "일본", "team": 2 }, { "name": "봉천", "team": 1 } ]` - factions with the same number (>=1) are fixed allies. `team` omitted · 0 = no team (enemy to everyone). If factions is absent or the map is generated, **all factions are enemies of each other**.
- **Rulings**: `World.Allied(a, b)` = same faction or same team (neutral 0 excluded), `World.IsHostile(a, b)` = different non-neutral factions that are not allied. Every engagement · auto-target · forced attack (`Attack`/`Charge` validation) · push-away hostile mask · capture contest · AI `IsRival`/`IsHostile` uses only these. `Allied` is used for vision sharing (`FogOfWar.ShareAlliedVision`), alert sharing (`Detection`), ammo recovery "friendly city" (`Supply.IsFriendlyCity`), joint victory (`AllMutuallyAllied` → `Winners`).
- **Immutable**: teams are set once from the map definition in `CreateStandard` (`World.AssignTeam`, pre-start setup only - tests use it too) and there is no command. `Faction.Team` is included in the snapshot (`FactionSnapshot`) · checksum · `Audit` (FormatVersion 9). Combat-test world = no teams (1 vs 2 enemies).
- **Deleted**: `Diplomacy` relation table · proposals · log (`DiploEvent`), skirmish (damage between neutrals → temporary hostility), `DeclareWar/Propose/Respond/BreakAlliance/TransferUnits` commands (replay format 5), `DiplomacyWindow` · F10 · `--diplo`, `StandardAiDiplomacy` (containment coalition · betrayal · support), `balance.json diplomacy` (`DiplomacyDef`), `World.StartedAtWar` · replay/snapshot header `StartAtWar`, the `CreateStandard(startAtWar)` argument. The sound-effect file `diplomacy.wav` remains but is not played.

### Mission frame (미션 틀) (2026-10-19, `src/Core/Mission/` · `src/AI/MissionAi.cs` · `src/GameMission.cs` · `src/UI/MissionMenu.cs`, test `Tests/MissionSelfTest.cs` = `KD_SELFTEST_ONLY=missions`)
- **File** `assets/missions/<id>.json` (comments · trailing commas allowed). Coordinates = tiles, `facing` = compass angle (0 north · 90 east · 180 south · 270 west, multiples of 45° are exact table values). Top level: `id` `title` `date` `location` `briefing` · `map` (existing map id) **or** `mapData` (same object as a map file, `starts` any value with 2 or more entries - the mission overwrites it with each faction's first force position) · `seed` · `weather` · `time` (stored and passed through as is - the effect belongs to the weather work, partial hook `World.OnMissionWeather` when changed) · `player` (human faction number).
- `factions[]`: `name` `en` `lang` `color` `team` (instead of the map factions) + AI hints `posture` (attack · defend · hold) · `area` (hold zone / attack target zone name) · `ai` (controller name, default `mission`, `none` = none) · `aiProfile` (tactical AI profile name, overlap such as `korean+stage2` possible) · `aiWithdrawAt` (stage 3A: withdrawal threshold = force ratio 0 to below 1; below this the AI abandons the objective and withdraws to defend - 0 = to the end, if absent the profile `withdrawAt`, default 0) · `aiCommitment` (how firmly the objective is held 0~1, 0.5 = profile as is, attack limit · withdrawal threshold multiplier 2 × (1 − value); if absent the profile `commitment`).
- `areas{name: {rect:[x,y,w,h]} | {circle:[cx,cy,r]}}` · `deployZones[] {faction, rect|circle}` (player deployment zones).
- `forces[]` = one deployment unit = a bundle dragged in the deployment phase: `id` `faction` `name` `at:[x,y]` (or `area`) `facing` `formation` (company formation line · column · box · spread · wedge · free) · **battalion** = `companies:[{units:{type:count}, formation, rank, tag, company}]` + `battalion` (number, default = an unused number if there are 2 or more) · `battalionForm` (line · column · echelon · reserve) · **loose bundle** = `units:{...}` + `rank` + `tag` + `company` (default: a company if there are 2 or more infantry). `rank` = rank step (starts with as many kills as combat.rankKills gives), `tag` = name that objectives · events call (officer · guns · wagon ...), `deployable` (default = player faction + inside a deployment zone), AI hints `posture` · `aiArea` (this force only).
- `reinforcements[]` = same format as forces + `time` (seconds, if absent only via the event spawn) · `area` (appearance zone name → center).
- `objectives[]` `{id, type, text, primary (default true), hidden}`: **capture** `area` `seconds` (accumulates time while only our capture-capable units are in the zone · decreases while only enemies are · pauses when mixed) · **eliminate** `percent` (default 100 = annihilation, based on the number of enemies that appeared) or `tag` (all tagged units) · `faction` (default = all of the player's enemies) · **defend** `seconds` (+ `area` · `loseAfter` default 10 seconds: fails if an enemy holds it alone) · **escort** `tag` `area` `count` (default 1; fails if living tagged units are fewer than count). Victory = all primary objectives complete, defeat = any one primary objective failed · defeat condition · player annihilated (no pending reinforcements).
- `failures[]`: `losses` `percent` (player losses %) · `keyUnit` `tag` (if even one dies) · `timeLimit` `seconds` (primary objective not complete by then). Override the wording with `text`.
- `events[] {id, when:{...}, do:[...]}` (once only, all conditions must be true): when = `time` (seconds or more) · `area` + `faction` (default player, any one unit enters) · `objective` + `state` (done default · failed) · `killed` (tagged units annihilated). do = `spawn` (reinforcement id) · `message` · `weather` / `time` (time of day) · `reveal` (objective id).
- **Execution**: `World.CreateMissionWorld(def, defs, seed, deployment)` - no metropolis, map facilities as is, victory/defeat via `UpdateMission` (branched from WorldCapture.UpdateVictory). State `World.Mission` (`MissionState`: objective state/progress/reveal · events · reinforcements · per-force unit Ids · tags · starting rank · spawn count · messages · weather · result) = snapshot `MISN` section (includes the mission JSON original text) · checksum `HashMission` · Audit. FormatVersion 14 (MISN = after WTHR), replay 7; starting weather = SetupWeather by CreateMissionWorld, event weather = partial OnMissionWeather (Weather.cs) (header `Mission` = JSON + deployment list), snapshot header `Mission` = id.
- **Deployment phase**: only before the first tick (`Mission.Started == false`), `ApplyDeployment(force, center, direction)` - positions are recomputed from the definition + the final (center, direction) (same result however many times it is moved), no fog update. The final list (`Mission.Deployment`, in force id order) is kept in the replay header to reproduce the same tick-0 state. Game: drag = move, R / right-click = 45° rotation, Enter / [Start operation] (작전 개시) = start. Only `MissionEndCommand` (console `mission win|lose`, cheat) is a new command.
- **AI** (2026-10-19 tactical AI integration): the default AI of mission factions = `TacticalAi` + `SetDirective` (`World.AttachMissionAi`): faction `posture` attack/defend/hold → `AiPosture`, `area` → center · radius (attack = advance to the zone - the objective when no enemy is visible, defend = place to guard, hold = hold area; with no zone, the initial position · hold radius 12), `aiProfile` → profile (unknown name falls back en → default; `japan_garrison` added). An auxiliary `MissionAi` (`mission-aux`) is attached to the same faction and handles **unarmed groups (escort wagons: toward the objective zone, never more than 6 tiles ahead of the armed force's center) and reinforcements (the tactical AI ignores new units after the initial organization)**, and the tactical AI removes unarmed units from the organization with `SetSkipUnarmed`. Per-force `posture` · `aiArea` apply only to the auxiliary AI (reinforcements) - the tactical AI receives only faction-level directives (limitation: scattered ambush groups' hold merges into a single defensive line). `ai: "mission"` = the old standalone AI (for comparison), switch the default with the `KD_MISSION_AI=mission` environment variable to compare. Old standalone `MissionAi` rules: attack = attack-ground on the nearest visible enemy → objective zone → enemy start position, defend = Hold at the initial place (auto trench) + counterattack only enemies within 8 tiles, hold = counterattack only enemies inside the zone, unarmed (wagon) = move only to the objective zone.
- **Screens**: start screen [Mission] (미션) → list → briefing (map preview · objectives · defeat conditions · force summary) → [Start deployment] (배치 시작) / [Start now] (바로 시작). In game, objective panel at top left (progress · time left) + event messages; at the end a result screen (victory/defeat · time · losses · kills · top killer · promotions · objectives) + result json `%LOCALAPPDATA%/KoreanDivision/results/<id>_<time>.json` · `<id>_last.json` (change with `KD_RESULTS_DIR`, surviving units · ranks = for campaign carry-over).
- **Spectate mission** (관전 미션) (2026-10-19): top-level `"spectate": true` → the game is in spectate mode (no deployment phase, all factions AI). Sample `ai_kr_vs_ft_1000` (Korean army 978 vs Fengtian army 999, central village encounter battle, organization table = file `_doc`; Korean army wins on all 3 seeds · 160~220 seconds). Appears in the mission list automatically.
- **CLI**: `--mission <id>` (from the deployment phase) · `--mission-start` (skip deployment) · `--mission-run <id> [--seconds N] [--seed N] [--verify] [--deploy force:x,y,angle]` (all factions AI without a window until the result, prints result json · checksum) · `--menu-page missions|briefing` (`KD_MENU_MISSION=<id>`) · `--uifuzz N --mission <id>`.

### Campaign 1-2 Tumen River crossing · force carry-over (캠페인 1-2 두만강 도하 · 병력 이월) (2026-10-20, c102)
- Mission `assets/missions/c1_02_tumen.json`: cross the river (2 fords, spring mud = sand band), capture the ferry village and hold 4 minutes (primary), secure the 2 fords (secondary 2). 3 battalion companies (60 men) + machine-gun company + howitzer company + observer team vs bandits + Fengtian garrison (faction 3, same team) 732, defeat at 60% losses, 6000-second limit. AI vs AI seeds 1~5 (no carry-over): 2 wins 3 losses (defeat at 60% losses).
- **Carry-over**: top-level `"carry": true` → `MissionDef.Load` uses `CampaignCarry.Patch` to build text in which the campaign state's surviving riflemen (`Unit == "infantry"`, selected by highest rank → placed in previous company id order) are written into force `b1` company `infantryRanks`, and company officers (in rank order) into `officerRanks`/`officerXp`. Missing slots = replacements (default rank, squad leaders by the default rule). No sim rule change - snapshot · replay carry the written text. `MissionCompany.InfantryRanks` is applied by SpawnForce in order to rifle infantry (excluding officers · heavy weapons · scouts).
- `CampaignState`: `HowitzerCompany` (1-2 victory), `Entry*` (the forces a finished mission first received - redo starts with the same carried force, `CarryFor`). Menu: 1-2 open, 1-3 in preparation, [Redo] (다시 하기) = the last finished mission. Test `KD_SELFTEST_ONLY=missions` (`Campaign2Checks`).

## Command convenience ①⑤ battle autosave · result report (지휘 편의 ①⑤ 전투 자동 저장 · 전과 보고) (2026-10-22, T17 = restored old `battlereport`)
- In-mission save = existing HUD save button · F6 (`.kds`). Autosave just before a big battle = `Game.BattleAutosave`: after 20 seconds with no firing, at a tick boundary where `World.Shots` reaches 6 or more at once, overwrites a single slot `autosave_battle` (minimum interval 2 minutes, missions only, world read-only - sim · save format unchanged, FV unchanged). Constants `SaveManager.Battle*`.
- Result report = result screen `DrawBattleReport`: casualty causes per faction (fire · melee · shelling %, `MoveStats.LossCause` measurement only - starts from 0 after loading) + per-company survivors/organized/kills for friendly companies. `MissionResults.LossCause/Companies` (JSON extra fields).
