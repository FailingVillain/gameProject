# Engine notes - combat-core (combat overhaul stages 1~4, armor immunity, engagement distance · cover, combat tweaks) (엔진 노트 - combat-core (교전 개편 1~4차, 장갑 면역, 교전 거리·엄폐, 전투 조정)) [split from ENGINE_NOTES.md 2026-10-23, body verbatim]

### Combat overhaul stage 1 (교전 개편 1차) (2026-10-18, ROADMAP §2-5)
- **Weapon fields** (`WeaponDef`): `cooldownMin/Max` (per shot `World.NextCooldown` = hash Roll(shooter Id, tick), `cooldown` if absent), only `accNear/accFar` (`World.AccuracyCurve` = near − (near−far)·(d/range)², accMid deleted), `fire: direct|indirect` (`WeaponDef.Indirect` -> `World.IsIndirect`; if omitted, splash>0 = indirect), `los: true` = direct-fire line check (`World.HasFiringLine` -> `GameMap.HasLineOfSight(a, b, ignoreA, ignoreB)`, the shooter's and target's building footprints are passed through; if blocked, approach when chasing · otherwise drop the target, `FindTarget(..., losFrom)` takes only candidates with a line). Rifles have no los.
- **Gun deployment**: every unit with `setupTime > 0` (field gun · infantry gun · howitzer) uses `DeployPhase` - automatic with no command (target within range -> `AdvanceDeploy`, move · chase -> `AdvancePack`). Not pushed while deploying · deployed. A deployed unit without a turret must have its hull facing the target to fire (`AimedAt`).
- **Hull turn rate** (2026-10-19, HANDOFF 4m): unit `turnRate` (deg/s, `UnitDef.TurnRadPerSec`; omitted = default 14 rad/s ≈ instant) - infantry gun 45 · field gun 30 · howitzer 20. Shared by movement (`MoveToward`) · aiming (`FaceToward`, within the deployed arc `ClampTraverse`) · flag idle rotation. While moving, if the hull is off the travel direction, speed × max(0.2, cos error), and while cos < 0.5 the stall judgement (`CheckProgress`) is deferred. On arrival it does not snap to the formation direction (keeps the current direction). Target outside the arc = if the angle to move is < 90° the gun turns while deployed (turnRate × 0.5, N10), an attack command beyond that = pack up -> turn (at this speed) -> redeploy.
- **Overlap resolution** (`World.SeparatePair`): fixed = holding · construction · deployed (all phases) · firing posture (`Unit.Engaging` = Target + AimTarget). For an allied pair the moving side 1 : the standing side 0.25; for a hostile pair (`sepHostile` bit) no pushing, and only the side that actually moved this tick undoes its own overlap. Push per unit per tick ≤ `World.MaxSeparationStep` (0.25 tile). -> **Redesigned 2026-10-18** (section '충돌 · 대형 재설계' (collision · formation redesign) below: accumulate then apply once · damping · margin · per-state weights).
- An observation line at the end of `--balance sim` (shots · hits · deaths · rounds per kill).


### Combat overhaul stage 2 (교전 개편 2차) (2026-10-18, ROADMAP §2-4b~g · §2-6)
- **Files**: `src/Core/Combat3.cs` (Unit: `Suppression` short · `Kills` short · `ChargeState` byte · `HesitateBlockUntil` long - all [SnapExt], in the latter part of the CMB2 section `WriteCombat3/ReadCombat3`, checksum `HashCombat3`; FormatVersion 4). Values in `Defs.CombatRules` (balance.json `combat`), weapon `suppress` · `spray`, unit `melee` · `suppressResist` · `commandRadius`.
- **Target spreading**: `FindTarget(..., shooterId, jitter)` - unit candidate score = distance (+100 unarmed) + jitter × `PairNoise(shooter, candidate, seed)` ∈ [0, jitter). A tick-independent hash, so the same preference on re-search. Direct-fire infantry only (`TargetJitter`), building candidates unchanged. No change in candidate iteration cost.
- **Target search cost**: `TryAcquire` interval `acquireInterval + Id % acquireStagger`, direct-fire unit radius `min(radius, acquireRadiusCap)` (indirect excluded). A target is kept while valid (alive · visible · hostile) - re-search only when there is no target (existing behavior).
- **Suppression**: `Suppress(target, w)` is called by `Fire` (direct) · `Explode` (gun landing - everyone within the radius on the landing tick) · `FireSpray` (everyone within the radius of the impact point) - regardless of hit, increase = suppress × `Def.SuppressResist` (0 = immune). `DecaySuppression` every 15 ticks (Id-staggered) integer decrease = 80 × 0.25 × (1 + rank × 0.25) × (3 near an officer). Effects: `FireIntervalMul` (multiplied onto the fire cooldown: ×(1+s/1000), ×0.9 near an officer) · `UnitSpeed` (movement: ×(1−0.5·s/1000), charge ×1.3) - `MoveToward` · `FollowGroup` use it instead of `Def.Speed`. No effect on hit chance.
- **Officers**: `Def.CommandRadius > 0`. `RebuildHash` regathers the `officers` list and `NearOfficer(u)` looks only at the distance to a same-faction officer (no stacking, no cache - called only in the 15-tick decay · firing · 1-second hesitation checks). Officers themselves · enemy officers do not apply. **Does not engage first** (user 2026-10-19, `WorldCombat.OfficerPassive`): while idle · attack-moving, the auto-target radius = own weapon range (+ radius), no chasing · approaching (chase false). Exceptions: during a charge (sword-charge command · melee auto-charge) · explicit attack command (Order Attack). Test `CleanupSelfTest`.
- **Rank**: `Damage` -> `CountKill` (if target Hp ≤ 0, shooter Kills+1, bombardment included). `Unit.Rank` = `CombatRules.RankOf(Kills)` (officer −1). HUD `Hud.RankName`. (2026-10-19 ④: 9 ranks of private · NCO · squad - section "분대 · 부사관" (squad · NCO) below)
- **Charge**: `ChargeCommand(Units, Target, TargetId)` -> `ExecCharge`: designated enemy = Order Attack + ChargeState 2, a point = Order AttackMove + new MoveGroup + ChargeState 2 (no formation). Automatic = `AutoCharge` (in Engage · TryAcquire, not holding · unit target · distance ≤ chargeAutoRange -> ChargeState 1); even while aiming at a far target, every 15 ticks a radius-2-tile `FindTarget` looks for an enemy underfoot (attack commands excluded). On the first line of `Engage`, if `Charging` then `EngageMelee`: if edge distance ≤ meleeRange + weapon range, stop (AimTarget = target -> Immovable) and strike each cooldown with `Roll < accuracy` (recorded as `MeleeStrikes`, not Shots), otherwise chase. End: automatic = when the target disappears, command = ResetOrder (new command · designated target dead) or ArriveGroup. No ammo check · hesitation during a charge.
- **Engagement distance (A)** (revised in engage 2026-10-19: distance = `World.ReactRange` = range × weapon `engageFrac` or `engageRangeFrac` 0.7, hold · attack-move formation target search also use this radius, idle units under fire have no closeIn - see '교전 거리 · 엄폐 (engage)' (engagement distance · cover) below): `closeIn` of `Engage` = not chase · direct fire · gun (deployed + category gun) (machine guns · anti-tank rifles are included since 2026-10-19 - while approaching they release · move · re-mount) · `AimTarget != target` · distance > range × engageRangeFrac -> even within range, takes the chase branch to approach. After aiming begins, keeps firing as long as within range (prevents going back and forth).
- **Reaction delay · hesitation**: `Acknowledge` -> `ReactDelay = Roll(Id, 0x7E57) × (max+1)` (0~3 ticks). `MaybeHesitate` (UpdateUnitCore, when ReactDelay is 0): suppression ≥ 400 · not charging · every 60 ticks (Id-staggered) · walked last tick · `HesitateBlockUntil` has passed · 3 s have passed since a Move command -> probability = 0.15 × (s−400)/600 × (1 − rank × 0.25) × (officer 0.5) -> `ReactDelay` = 0.2~0.6 s, `HesitateBlockUntil = Tick + stopped ticks / 0.05` (duty ≤ 5%). Hesitation reuses the ReactDelay path (stands and looks toward the goal).
- **Machine gun spray**: `FireSpray` (weapon.spray > 0, unit shooter). The hit check is relative to the target; on a miss the impact point = target + a deterministic point within radius spray (`Roll` angle · √r), among other enemies within spray of the impact point a 1/(d+0.25)-weighted pick -> that unit is re-judged with its own hit chance. Suppression hits everyone within spray of the impact point; allies · non-hostiles get no damage · suppression. Machine gunners use the existing DeployPhase automatic flow with `setupTime 3 / packTime 2`.
- **Line-of-fire check (f)**: all infantry direct-fire weapons `los: true`. `GameMap.HasLineOfSight` blocks only impassable terrain · building-occupied tiles (city passable is passed through, units are not looked at). If blocked: chasing -> approach, holding -> drop the target, automatic search only takes candidates with a line.
- **Sound**: `Sfx.Muted` (user toggle, `--mute` · N key in game) and `Sfx.Silent` (turned on by Game while the engagement-test world `World.BattleMode`) each block Play · PlayAt · PlayVoice. ### Armor immunity and new units (장갑 면역 · 신규 유닛) (2026-10-19, ROADMAP §2-4f)
- Immunity = weapon `bonus.<category>: 0` (`WeaponDef.CanDamage`). `World.Damage` returns immediately if amount ≤ 0 (otherwise minimum 1). `FindTarget(..., weapon)`, for a weapon with a bonus, removes immune categories from candidates and gives the `preferCategory` category a score of −1000. Automatic charge is also not done against targets the melee weapon cannot damage.
- The AI judges an anti-tank unit by `WeaponDef.IsAntiArmor` (bonus > 1) - having a bonus does not make it anti-tank.
- New units are not in `produces`: only via `--battle "tank_ft_male:3" --vs "infantry:60"` · map placement. Art = theme.json alias (`unit.tank` / `unit.officer`).

### Engagement distance · cover (교전 거리 · 엄폐) (engage, 2026-10-19, `WorldCombat.cs` ReactRange · Retaliate, `src/Core/CoverSeek.cs`, AI `TacticalAi.Company.cs` DefendFortify, test `Tests/EngageSelfTest.cs` = `KD_SELFTEST_ONLY=engage`)
- **React range** `ReactRange(u)` = range × (weapon `engageFrac` > 0 ? that value : `combat.engageRangeFrac` 0.7), indirect · guns (category gun) = range. Used in: hold target search (old range), attack-move formation member search, chase closeIn. Machine gun · sniper rifle · pistol · submachine gun `engageFrac` 1.0. The idle (Idle) search radius stays at vision (closes in to the react range via closeIn).
- **Under fire** `UnderFire(u)` = `Tick − LastFiredAtTick ≤ underFireSec` (2.5 s, misses included - reuses the existing ammo-regeneration state, no new state). An idle unit under fire does no closeIn (returns fire in place).
- **Retaliation** `Retaliate`: idle · holding + attack-move company flag formation members (not charging · not officers, attacker within range) with no target take the enemy who shot as the target. Formation members fire standing per the hold rule (if more than a quarter engage, the flag stops).
- **Cover seeking** `UpdateCoverSeek` (UpdateUnitCore, after AutoGrenade): every `coverSeekTicks` (30) ticks Id-staggered, targets = idle · holding · no group · not charging · outside a trench · no spot · stationary · `CanOccupyTrench` · not a deployed weapon · under fire. `FindTrenchSpot(radius coverSeekRadius 3)` -> walk and EnterTrench; otherwise (current multiplier > trenchHit) `BestCoverTile` = among tiles with multiplier ≤ current − `coverSeekGain` 0.15, the minimum of (multiplier + 0.04 × distance), excluding deep forest · barbed wire, excluded if `coverSeekPerTile` 2 or more infantry are within 0.6 tile. 1-man MoveGroup + `CoverHold` = whether it was originally holding -> `ArriveGroup` -> `CoverOnArrive` returns it to holding. `ResetOrder` clears CoverHold. Cumulative `Stats.CoverSeeks/CoverSeekTrench`.
- **Position occupation** `OccupyPositionsCommand(Units, Target, Dir, Radius, CoverMaxHit)` (command, replay v11) -> `ExecOccupyPositions`: targets = infantry (CanOccupyTrench, with a weapon, not officers - deployed machine guns included). Candidates = trench spots within the radius (free ones · ones held by commanded units) with score `distance × (0.5 + trenchHit) − 0.3 × forwardness` + cover tiles (multiplier ≤ CoverMaxHit, per tile coverSeekPerTile − number of other infantry spots, ±0.22 tile beside, +0.5) -> sort by (score, spot) top N -> (distance², Id, candidate) greedy assignment. Assigned soldiers first all ResetOrder; trench = Claim + Walk/Enter, cover = 1-man move + CoverHold. Officers · leftover soldiers = box-formation move to point − dir × 3 + CoverHold. Cumulative `OccupyOrders/OccupyTrenchSpots/OccupyCoverSpots`.
- **Tactical AI defense** (`DefendFortify`, start of LineDefend · defending machine gun FireThink): trench (`trench` > 0, `NearestTrench(task position, max(6, trenchSearch × range), front)` - score distance − 0.5 × forwardness) -> cover anchor (`defendCover`, `World.CoverCluster` - 2-tile grid · max sum of (1 − multiplier) over ±3 tiles around) -> position occupation (radius max(8, front × 0.5 + 3)). Position move = changes by more than 8 tiles and not in contact · 20 s after the last command, a company that retreated (Spent) is kept if it is on a rear position. Advance -> 10% or less while moving, or 30 s -> Defend. If a frame (defense in depth), then the rear company's commander behavior (DrillHoldUnit does not touch soldiers on CoverHold · going to a trench spot). A position company sends no outposts. Retreat (defense) = `FallbackPost` (center − front × back around trench -> cover anchor, 4 or more tiles behind the current line) position occupation, otherwise the old quick step. Counterattack reserve = trench · cover anchor within 8 tiles of the reserve position. TacGroup.OccPost (AI state, not saved).
- **Defense front** (`BattalionThink`): the company front width cap of a defending battalion `defendSpacing` × range (0.65) - only when there is no trench around the battalion point.
- **Attack cover hop** `CoverHop` (LineThink approach): if the firing position is more than 10 tiles away, from 4 tiles ahead on the straight line, at 3-tile intervals, the first tile with BestCover(2) score ≥ 0.5 · current + 0.3 first.
- **Trench hit**: no distinction between occupying a trench and being on trench terrain - both are `TerrainCover` (trench 0.6). Fixed by a test.
- Measurement · sensitivity: `docs/legacy/BATTALION_CAMPAIGN_2026-10-19.md` '교전 거리 · 엄폐 (engage)', variants `KD_OBS_VARIANT=ENG<percent>[F]` · `NOFORT` · `NOSEEK` · `SPACE0` · `OLDDEF` (joined with `+`).

## N35 officer engagement avoidance · scout self-defense fire (N35 장교 교전 회피 · 정찰병 자위 사격) (2026-10-19, `src/Core/OfficerConduct.cs`)
- Officers: no charging alone - automatic charge (1 tile) · looking at an enemy underfoot · march-fire 3-tile charge · cavalry 'charge only' only when `OfficerChargeOk` (the company's infantry at `officerChargeWithFrac` 0.3 or more are charging); a charge command (`ExecCharge` - AI company · frame · player) only when received together with soldiers of the same company. When the company charge ends, the officer's charge ends too (`OfficerChargeEnd`). Even while charging, does not exceed the charging soldiers' front row + `officerChargeLeadTol` (`PaceOfficerCharge`, called from HeavyPacing `PaceOfficer`).
- Self-defense fire only (`PassiveFire` · `PassiveFireRange`): officer = enemy within `officerDefendRange` 4 tiles, or if the company is in melee within the officer's `officerMeleeRadius` 6 tiles, pistol range. Scout = within `scoutDefendRange` 4 tiles, and if stationary yet keeps being hit, returns fire at a shooter within `scoutRetaliateRange` 10 tiles (`PassiveRetaliate`). Hold · idle · attack-move target search · march-fire radius · retaliation all use the same rule, no chasing. Officer fire is subtracted from the 'engaged' count of an attack-move column (does not halt the column).
- `combat.officerAvoid` · `scoutAvoid` = false gives the old behavior (measurement variant `KD_OBS_VARIANT=OFFOLD`). No state added (save · checksum unchanged), measurement probes = `MoveStats.OffCharge` · `OffShot` · `ScoutShot` (`[장교교전]` · `[장교사격]` · `[정찰사격]` · `[장교위치]` of `--tactics-obs`). Test `KD_SELFTEST_ONLY=officer`.
