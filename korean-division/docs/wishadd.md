# wishadd — 추가 제안 (설계 단계, 사용자 재보고 후 결정)

> 2026-10-22 코디네이터 역제안 중 **"추가하면 좋을 것"**. 사용자: "설계 부분이므로 추후 재보고할 수 있게끔 wishadd.md 를 만들어둬." → 구현하지 않는다. 해당 설계 차례가 오면 사용자에게 다시 보고하고 승인받는다.
> (난이도 구조 처음부터 만들기 = 승인됨 → 구현 대기열 쪽에 있음. 여기 없음.)

## 시스템 (A)
- **A4 리플레이 하이라이트 · 되감기 분석** (中) — 교전 시작 시점 점프, 중대별 손실 곡선. 전과 보고 화면과 데이터 공유. AI 튜닝 · 밸런스 검증용.
- **A5 병합 후 회귀 요약 지표** (中) — 미션 10개 × 5분 요약(승패 · 손실 비율 · 교착 여부)을 병합 후 1회 자동 기록. `tools/agent/soak.ps1` 축약판. (※ 사용자 "전부 승인"에 따라 도구 자체는 승인됨; 지표 항목 · 임계값 설계는 재보고.)
- **A7 성능 예산 문서화** (下) — 틱당 시간 예산을 기능별로 `--stress` 로 기록. 1만 부하 시험(보류)과 3D 단계 병목 파악용.
- **A8 접근성 · 표시 옵션** (下~中) — 글자 크기, 색약 모드(팀색 외 모양 구분), 속도 기본값. 설정 메뉴 병합 뒤.
- **A9 (미룸)** 사진 모드, 연대장 위임 강화(방어/공격/지연 태도) — 장교 학파 구현 뒤로.

## 캠페인 (B)
- **B4 미션 목표 템플릿** (中) — 방어 · 호송 · 습격 · 도하 · 시간제 목표를 미션 JSON 템플릿으로. 에피소드 설계 병목 완화.
- **B5 분기 · 패배 데이터 모델** (中~上) — 분기 변수(북벌 진척 · 민심 · 본국 신뢰 · 학파 · 사상자 이력)를 하나의 상태표로 두고 미션 결과가 규칙으로 갱신. 엔딩 A~D 구현 단순화.
- **B6 브리핑 · 인물 초상** (中) — 황손 이태 · 민 대장 등 초상 + 짧은 대사를 브리핑 · 이벤트에 사용(SD.Next 파이프라인).
- **B7 조작 튜토리얼 이벤트** (中) — 화살표 안내 · 힌트 박스를 미션 이벤트로. 사격 통제 · 명령 대기열 도입 시점에.
- **B8 캠페인 테스트 도구** (下) — 미션을 건너뛰고 상태를 임의 설정하는 개발자 콘솔(`--campaign-set`). 에피소드 8개 구조 검증용.
- **B9 (미룸)** 연구 기능 — 장교 학파 · 장비 개량이 정해진 뒤. 캠페인 홈 MVP 에서는 제외.
