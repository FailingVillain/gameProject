## F1~F3 계획: 대형 강박 줄이기

### 원칙
- 대형은 **이동 (비접적) 에만**. 적을 보거나 사격받으면 (접적) 중대는 "구역" 으로 바뀐다.
- 접적 중의 기본 단위 = 분대. 병사는 대형 자리가 아니라 **분대 구역 안에서 엄폐 · 사계가 좋은 사격 위치** 를 고르고 거기서 싸운다.
- 대형 재정렬은 접적이 끝나고 일정 시간 뒤, 또는 명령이 있을 때만.

### 단계
1. **접적 상태 (중대별)**: 비접적 → 접적 (적 발견 · 피격 · 사거리 안 적) → 이탈 (N 초 교전 없음). 접적 중에는 빈자리 점검 · 대열 정비 (gapfill) · 자리 복귀 · 도착 판정을 끈다.
2. **구역 = 느슨한 닻**: 대형 자리를 반경 4~6칸 구역으로 바꾼다. 병사는 구역 안 엄폐 · 고지 · 사선이 열린 칸을 고른다 (기존 피격 엄폐 · 엄폐 찾기 재사용). 구역 밖으로 밀려날 때만 돌아간다.
3. **사격 위치 고정**: 사격 위치를 잡고 표적이 있으면, 제압 · 후퇴 · 명령 전까지 머문다 (최소 체류 시간 + 이동 문턱) → 왔다갔다 제거.
4. **회전 (F2)**: 방향 전환 = 구역 닻만 새 방향으로 다시 놓고 가까운 병사부터 다시 배정 (기존 `Formations.Match`). 대형 모양 전체를 돌리지 않는다. 병사는 제자리에서 방향만 바꾸고, 새 구역 밖일 때만 걷는다.
5. **전술 AI**: 틀 (tactics.json) 은 접근 국면에만 쓰고, 접적 뒤 AI 는 중대에 "구역 · 목표" 만 준다. 같은 중대에 이동 명령 재발령은 변위 문턱 · 최소 간격 이상일 때만.
6. **플레이어 조작**: 접적 중 이동 명령 = "선까지 전진" (분대 약진 · 행진 사격 재사용), 대형 모양 강제 없음. 대형 유지 명령 (예: 키 하나) 은 선택 사항으로 남김.

### 측정 (전 / 후, tactics-obs A/B/C 시드 1~5)
- 접적 중 사격 시간 비율 (목표: 오름), 접적 중 분당 이동 거리 (왔다갔다 = 내림), 대열 정비 · 자리 복귀 횟수 (크게 내림), 교환비 · 승률 (악화 없음), 스크린샷 / 영상 확인.
