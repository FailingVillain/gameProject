### Build · run
- Build: `"/c/Program Files/dotnet/dotnet" build -o bin/main`. Parallel agents use `-p:IntermediateOutputPath=obj/<id>/ -p:OutputPath=bin/<id>/`. Release needing a headless console uses `-p:OutputType=Exe`.
- Run: `dotnet run` (no args = start screen). Flags: `--map WxH|<mapId>` `--players N` `--faction n|name` `--seed N` `--ai tactical|tactical:<profile>|standard|passive|rush|battle|none` (default tactical = tactical AI) `--nofog` `--weather clear|overcast|fog|rain|snow` `--time dawn|day|dusk|night` `--demo` `--exec "<console command>"` `--shot f.png --shot-frame N` `--quick-battle [n]` `--battle "kind:count,.." --vs "..."` `--spectate` `--replay f` `--mute` (engagement tests are muted by default, N in game = sound on/off — this also lifts the engagement-test mute).
- Publish: `powershell -ExecutionPolicy Bypass -File publish.ps1` → `dist/KoreanDivision.exe` (single file).
- Verification: `--selftest` · `--detcheck [--update]` (golden checksum; update on sim change, `tools/detcheck.ps1` = CPU variants) · `--snaptest` (`KD_SNAP_QUICK=1`) · `--uifuzz` · `--stress` · `--balance`. Test temp files = `%TEMP%/KoreanDivision/run-<pid>-<ticks>/` (write only via `TestTemp.Child(name)`; deleted on normal exit, kept on failure with the path printed; env var `KD_TMP` sets the folder · inherited by child processes). ### Rules
- State changes only through commands (`WorldCommands.cs` → replay recording). The AI does not modify `World` directly; it sees only via `FogOfWar.CanSee`.
- Deterministic sim: DetMath, hash-based randomness, no dependence on wall clock · render state · dictionary enumeration order. New state field → checksum + `SnapshotSelfTest.Audit` + included in saves, bump `Snapshot.FormatVersion` on structure change.
- Balance values live only in `assets/data/balance.json`. Balance reports are observation only (values after user approval).
- Korean UI strings are consts in `src/UI/Strings.cs` (font atlas). Esc is cancel, not close window.
- Naming: namespace `KoreanDivision.*`, env vars `KD_*`, saves `.kds` (magic `KDSV`), replays `.kdr.json`.
