# Wargame 작업 계획

> 최종 목표: **나짓놀(나라짓고놀기)형 국가 게임** (참고: SC 유즈맵 "제국의 확장", "삼국시대 정외전", Hearts of Iron).
> 이 파일은 작업 순서 · 결정 사항 · 진행 상황을 기록한다. 각 단계를 끝낼 때마다 갱신한다.

## 전제 (2026-10-17 확정)
- **인원**: 기준 10인, 최대 24인
- **플레이 시간**: 5 ~ 10시간 (HoI 스타일) → 저장/불러오기 · 장시간용 경제 템포가 필요 (아래 "다음 후보")
- **외교**
  - 상태: 동맹 / 중립 / 전쟁. **시작 시 전원 중립**
  - 선전포고: **즉시 발효** (일방적)
  - 동맹 → 전쟁 **직행 가능** (배신 허용)
  - 동맹 · 휴전: 제안 → 수락 (제안은 만료 시간 있음)
  - 중립 상대: 자동 교전 · 자동 공격은 하지 않지만, **강제 지정 공격(공격 명령으로 대상 지정)은 가능**
  - 동맹: 시야 공유, 같은 거점에서 경합하지 않음
  - **공동 승리 인정**: 살아남은 세력이 모두 서로 동맹이면 함께 승리
- **지원 (송금 · 유닛)**
  - 송금 대상 제한 **없음** (전쟁 상대에게도 가능)
  - 유닛 지원으로 받는 쪽 **인구 초과 허용** (기존 유닛 유지, 생산만 막힘)
  - 자원은 여러 종류를 담을 수 있는 구조 (지금은 "자금" 하나)

## 다음 후보 (이번 범위 밖)

- 한글 이름 · 채팅 (폰트에 한글 11,172자, raylib 한글 조합 미리보기 한계)
- 온라인 멀티플레이 (명령 객체 위에 락스텝 네트워크), 실수 결정성 점검

- 정리: F9 디버그 제거, 공구 90% · 포탑 85% 명중률 확정
