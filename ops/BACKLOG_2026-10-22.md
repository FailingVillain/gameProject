# BACKLOG 2026-10-22 - 대기 작업 큐 (48개, 지휘자 사용 표)
사용법 1: 에이전트가 끝나면 지휘자가 이 표를 위에서부터 훑어, 충돌 그룹이 현재 실행 중인 작업과 겹치지 않는 하급(下·中) 작업을 꺼내 발주한다.
사용법 2: '충돌 그룹'이 같은 항목은 동시에 돌리지 않는다. 그룹 '-' 는 읽기 전용이라 어느 것과도 동시 가능.
사용법 3: 선행조건 '병합 후' = 해당 병합이 merge/0.2-final(또는 main)에 반영된 뒤. heavy '예' = 빌드·렌더·selftest 를 돌림(LIMITS.md 한도 적용).
사용법 4: 상급(上)은 표시용으로만 올렸다(발주 전 지휘자 판단). 결정 대기·보류 항목은 표 아래에 따로 모았고 큐에서 제외했다.
사용법 5: 이름은 '한글 이름(ID)' 형식(ops/CARD_NAMES.md). ID 가 아직 없는 후속은 '(ID 미부여)' - 발주 때 card_id.ps1 로 예약. 새 역할·절차 없음.
