# Korean Division — 캠페인 에피소드 설계

> 사용자가 내용을 채우고 Claude 가 미션 · 지도 생성 파라미터로 옮기는 문서.
> 규칙 · 자원 · 인물 = `korean-division/docs/CAMPAIGN_HOME_DESIGN.md`, MVP = `CAMPAIGN_MVP_SPEC.md`, 원본 기획 = `korean-division/docs/korean-division-design.txt`.
> 형식: 작전마다 아래 **블록 하나** (키: 값). 모르는 칸은 `?` 로 두면 Claude 가 묻는다. 칸 단위 = 게임 타일 (병사 1명 ≈ 1칸).

## 공통 규칙 (확정)
- 작전 종류: **큰 교전** (에피소드당 1, 1~2시간) · **중형** (1~2, 30~45분) · **소형** (2~4, 10~20분; 틀 = 마적 토벌 · 호송 · 정찰 · 거점 · 철도 차단, 일부 **선택**). 처음엔 하한 (중형 1 · 소형 2).
- 패배: 큰 교전 · 중형 = **재도전 (대가 없음)**, 소형 = **분기**.
- 지도: 자동 생성 → 사용자 수정. 중·소형은 **같은 에피소드 큰 교전 지도의 일부 구역** 재사용.
- 투입: 대대 단위 (+중대 빼기/더하기), 실제 투입 = min(보급 한도, `maxDeploy`).
- 황손 이태 = 챕터 1부터. 튜토리얼 = 시스템 익히기만.
- **공통 패배 조건 (확정, 2026-10-21)**: **쓰러진 병사 (사망 + 부상, 전투 불능) 50% 이상이면 패배** — 모든 일반 미션 기본값. **캠페인 변수 `maxCasualtyFrac`** (기본 0.5) 로 조정, 미션별 덮어쓰기 가능. (Claude 제안: 민 대장 강행 명령이 이 값을 올리는 식으로 부조리 축과 연결.)
- **정찰 분대 = 대대 직할** (Claude 권장): 1918년 무렵 대대 정보 · 정찰반이 표준, 부사관이 이끄는 4~6명 적절. 게임에서도 장교 없이 정찰병만 묶는 규칙 (N12) 과 맞음.

```
events: 대사/쪽지/증원/본국 명령 (황손 · 민 대장 · 이석 · 남 참장 · 김주현)
rewards: 보급 · 노획 · 신병 · 민심 · 해금
notes: 자유 메모
```

```
  합계 ≈ 보병 · 장교 · 부사관 510 + 경기관총 12 + 중기관총 4 + 보병포 2 + 기병 41 + 정찰 12 ≈ **580~600**

안개: **초소 1곳만 처음부터 보임, 나머지는 안개 속** (사용자) — 정찰 분대 · 기병으로 찾게.
적 (사용자 안): 마적 250 = 소총수 150 · 잡병(대도) 70 · 기병 30 (초소 2개 격파 뒤 이벤트 출몰). 산채 · 초소 3~4 에 분산.
도하: **다리 여러 개** (사용자) — 강행 도하 없음. 다리마다 초소/경계병을 두면 다리 선택이 첫 전술 판단이 됨.
가르치는 순서 (Claude 제안): 초소 1 = 중대 대형 · 공격 이동 · '교전!' → 초소 2 = 맥심 거치 · 제압 + 측면 기동 (1대대 제압, 2대대 우회) → 기병 습격 이벤트 = 기관총 · 착검으로 기병 돌격 막기 → 초소 3~4 = 보병포 직사 · 대대 선택 (Alt+숫자) → 산채 = 제압 후 돌격/착검. 단계마다 김주현 쪽지 1개.
```

## 스토리 초안 반영 (사용자 2026-10-21 — 원문 = `korean-division/스토리 설계 - 초안.txt`)
- **루트 구조 (사용자 확정 2026-10-21)**: 챕터 3-1 대토벌 · 3-2 대반란 **둘 다 본편**, 스토리상 **정사 = 3-2**. 본편에서는 둘 다 **챕터 4-1 (하얼빈, 정사)** 로 이어짐. **DLC 1 = 챕터 4-2 대한 공화국** (DLC 있으면 3-x 뒤 4-2 전개 가능). **DLC 2 (최종 DLC 예상) = 챕터 5 만주 원수** (이름 재검토 권장 — "만주국" 연상).
- **작전 등급 규칙 확정**: 메인 = 큰 교전 (필수) · **서브 미션 = 中 수준 교전, 필수** · **소형 작전 = 小 수준 교전, 선택** (선택 교전은 실패할 수 있음 → 분기).
### 챕터 1 에피소드 1 — 안동 점령전 (황손 이태 첫 등장)
- 소형 A (선택) 비적 소탕 — 압록강 이북 마을의 마적 소탕. 보상: 지역 평판 ↑ · 서간도 의용병 100 합류. 대가: 황손 비호감 ("시간 낭비").
- **서브 (필수) 교두보** — 안동 근처 압록강 서쪽 어귀, 봉천군 섬멸. 보상: **야전포 해금만** (곡사포는 뒤 에피소드로, 사용자).
- 소형 B (선택) 위력 정찰 — 봉천군 기밀 문서 탈취. 보상: 안동 봉천군 정보 → 메인에서 적 배치 일부 공개.
- 소형 C (선택) 약탈 금지 — 안동 북부 마을 마적 궤멸. 보상: 평판 ↑. 대가: 황손 비호감.
- 소형 D (선택, 어려움) 기병 대 기병 — 봉천 기마 정찰대 소탕. 보상: 메인에서 봉천군 전력 약화.
- **메인 (필수) 안동 포위전** — 승리 = **안동 포위 상태에서 핵심 거점 3곳 점령 + 적 30% 이상 소탕 → 봉천군 항복** (사용자). 보상: 은괴 상당량.
  - **일본 철도 부속지**: 본국 지시 "부속지에는 쏘지 말 것", **관동군 장교 + 보병 몇 명 주둔** (관동군 복선, 사용자).
- **시점 · 선택지 (사용자 2026-10-21)**: 에피소드 사이 '시점' (A1 · A2 · A3 …) 마다 선택지 — **여러 개 고를 수 있음** (자금 · 무기 소모). 반응 대상 = 황손 · 민 대장 · 장교 · 병사 사기 · 지역 평판 (**수치 이름 통일은 추후**), 호감치는 사용자가 조정 중. 선택지 원문 = `korean-division/스토리 설계 - 초안.txt` (사용자가 수정 중, 추후 정밀화).
